Go 输出函数

  • Go 常量
  • Go 格式化动词

Go 有三种函数用于输出文本：

  • Print()
  • Println()
  • Printf()

Print() 函数

Print() 函数以默认格式打印其参数。

实例

打印 i 和 j 的值：

package main
import ("fmt")

func main() {
  var i,j string = "Hello","World"

  fmt.Print(i)
  fmt.Print(j)
}

结果：

HelloWorld

实例

如果我们想在新行中打印参数，我们需要使用 \n：

package main
import ("fmt")

func main() {
  var i,j string = "Hello","World"

  fmt.Print(i, "\n")
  fmt.Print(j, "\n")
}

结果：

Hello
World

提示：\n 创建新行。

实例

也可以仅使用一个 Print() 来打印多个变量：

package main
import ("fmt")

func main() {
  var i,j string = "Hello","World"

  fmt.Print(i, "\n",j)
}

结果：

Hello
World

实例

如果我们想在字符串参数之间添加一个空格，我们需要使用 " "：

package main
import ("fmt")

func main() {
  var i,j string = "Hello","World"

  fmt.Print(i, " ", j)
}

结果：

Hello World

实例

如果两个参数都不是字符串，则 Print() 会在参数之间插入一个空格：

package main
import ("fmt")

func main() {
  var i,j = 10,20

  fmt.Print(i,j)
}

结果：

10 20

Println() 函数

Println() 函数与 Print() 类似，不同之处在于参数之间添加空格，并在末尾添加换行符：

实例

package main
import ("fmt")

func main() {
  var i,j string = "Hello","World"

  fmt.Println(i,j)
}

结果：

Hello World

亲自试一试

Printf() 函数

Printf() 函数首先根据给定的格式化动词格式化其参数，然后打印它们。

在这里，我们将使用两个格式化动词：

  • %v 用于打印参数的值
  • %T 用于打印参数的类型

实例

package main
import ("fmt")

func main() {
  var i string = "Hello"
  var j int = 15

  fmt.Printf("i has value: %v and type: %T\n", i, i)
  fmt.Printf("j has value: %v and type: %T", j, j)
}

结果：

i has value: Hello and type: string
j has value: 15 and type: int
