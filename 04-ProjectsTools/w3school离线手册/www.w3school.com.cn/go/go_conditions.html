Go 条件

条件可以是真或假。

Go 支持数学中常见的比较运算符：

  • 小于 <
  • 小于或等于 <=
  • 大于 >
  • 大于或等于 >=
  • 等于 ==
  • 不等于 !=

此外，Go 支持常用的逻辑运算符：

  • 逻辑与 &&
  • 逻辑或 ||
  • 逻辑非 !

您可以使用这些运算符或其组合来为不同的决策创建条件。

例子 试一试
x > y 试一试
x != y 试一试
(x > y) && (y > z) 试一试
(x == y) || z 试一试

Go 有以下条件语句：

  • 如果指定条件为真，则使用 if 来指定要执行的代码块
  • 如果同一条件为假，则使用 else 来指定要执行的代码块
  • 如果第一个条件为假，则使用 else if 来指定要测试的新条件
  • 使用 switch 来指定要执行的许多替代代码块
