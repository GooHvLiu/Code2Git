Go 语法

Go 文件由以下部分组成：

  • 包声明
  • 导入包
  • 函数
  • 语句和表达式

请看下面的代码，可以更好地理解它：

实例

package main
import ("fmt")

func main() {
  fmt.Println("Hello World!")
}

亲自试一试

例子解释

第 1 行：在 Go 中，每个程序都是包的一部分。我们使用 package 关键字来定义它。在本例中，该程序属于 main 包。

第 2 行：import ("fmt") 允许我们导入 fmt 包中包含的文件。

第 3 行：空行。Go 会忽略空格。在代码中保留空白可以提高其可读性。

第 4 行：func main() {} 是一个函数。其花括号 {} 内的任何代码都将被执行。

第 5 行：fmt.Println() 是 fmt 包中提供的函数。它用于输出/打印文本。在我们的例子中，它将输出 "Hello World!"。

注意：在 Go 中，任何可执行代码都属于 main 包。

Go 语句

fmt.Println("Hello World!") 是一条语句。

在 Go 中，语句以结束一行（按下 Enter 键）或以分号 ; 分隔。

按下 Enter 键会在行尾隐式地添加 ;（在源代码中不会显示）。

左花括号 { 不能放在一行的开头。

运行以下代码，看看会发生什么：

实例

package main
import ("fmt")

func main()
{
  fmt.Println("Hello World!")
}

Go 紧凑代码

您可以编写更紧凑的代码，如下所示（不推荐这样做，因为它会使代码更难以阅读）：

实例

package main; import ("fmt"); func main() { fmt.Println("Hello World!");}
