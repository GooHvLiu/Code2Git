开始使用 Go

要开始使用 Go，您需要两样东西：

  • 一个文本编辑器，如 VS Code，用于编写 Go 代码
  • 一个编译器，如 GCC，用于将 Go 代码转换为计算机能理解的语言

有许多文本编辑器和编译器可供选择。在本教程中，我们将使用一个 IDE（见下文）。

安装 Go

您可以在 https://golang.org/dl/ 上找到相关的安装文件。

请按照与您的操作系统相关的说明进行操作。要检查 Go 是否已成功安装，您可以在终端窗口中运行以下命令：

go version

该命令应该会显示您的 Go 安装版本。

安装 Go IDE

IDE（集成开发环境）用于编辑和编译代码。

流行的 IDE 包括 Visual Studio Code (VS Code)、Vim、Eclipse 和 Notepad。这些都是免费的，它们都可以用来编辑和调试 Go 代码。

注意：基于 Web 的 IDE 也可以工作，但功能有限。

我们将在教程中使用 VS Code，我们认为这是一个很好的起点。

您可以在 https://code.visualstudio.com/ 上找到最新版本的 VS Code。

Go 快速入门

让我们创建我们的第一个 Go 程序。

  1. 启动 VS Code 编辑器
  2. 打开扩展管理器，或者按 Ctrl + Shift + x
  3. 在搜索框中输入 "go" 并按回车键
  4. 找到 Google GO 团队提供的 Go 扩展并安装它
  5. 安装完成后，按 Ctrl + Shift + p 打开命令面板
  6. 运行 Go: Install/Update Tools 命令
  7. 选择所有提供的工具并点击 OK

VS Code 现在已经配置为使用 Go。

打开一个终端窗口并输入：

go mod init example.com/hello

如果您不理解为什么我们输入上面的命令，请不要担心。只需将其视为您总是做的事情，并将在后面的章节中了解更多信息。

创建一个新文件（File > New File）。复制并粘贴以下代码，并将文件保存为 helloworld.go（File > Save As）：

helloworld.go

package main
import ("fmt")

func main() {
  fmt.Println("Hello World!")
}

现在，运行代码：在 VS Code 中打开终端并输入：

go run .\helloworld.go

Hello World!

恭喜！您现在已经编写并执行了您的第一个 Go 程序。

如果您想将程序保存为可执行文件，请键入并运行：

go build .\helloworld.go
