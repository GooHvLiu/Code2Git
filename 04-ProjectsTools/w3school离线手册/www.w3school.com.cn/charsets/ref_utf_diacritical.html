UTF-8 变音标记

  • 修饰语字母
  • 希腊文和科普特文

范围：十进制 768-879，十六进制 0300-036F

如果您希望在 HTML 中显示特殊字符，可以使用下表中的 HTML 实体。

如果字符没有 HTML 实体，则可以使用十进制（dec）或十六进制（hex）引用。

实例

<p>我会显示 a</p>
<p>我会显示 &#771;</p>
<p>我会显示 a&#771;</p>

将显示为：

我会显示 a
我会显示 ̃
我会显示 ã

亲自试一试

较老的浏览器可能不支持下表中的所有 HTML5 实体。

Chrome 和 Opera 的支持是很好的，而 IE 11+ 和 Firefox 35+ 支持所有实体。
