UTF-8 C0 控制符和基础拉丁文字符

  • HTML UTF-8
  • 拉丁文补充

范围：十进制 0-127，十六进制 0000-007F

该字符集与原始 ASCII 字符集相同。

如果您希望在 HTML 中显示特殊字符，可以使用下表中的 HTML 实体。

如果字符没有 HTML 实体，则可以使用十进制（dec）或十六进制（hex）引用。

实例

<p>My name is &quot;Bill Gates&quot;</p>
<p>My name is &#34;Bill Gates&#34;</p>
<p>My name is &#x0022;Bill Gates&#x0022;</p>

会显示为：

My name is "Bill Gates"
My name is "Bill Gates"
My name is "Bill Gates"
