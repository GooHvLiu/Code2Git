UTF-8 C1 控制字符和拉丁文-1补充

  • 拉丁文基础
  • 拉丁文扩展 A

范围：十进制 128-255，十六进制 0080-00FF

如果您希望以 HTML 显示这些字符中的任何一个，则可以使用下表中的 HTML 实体。

如果字符没有 HTML 实体，则可以使用十进制（dec）或十六进制（hex）引用。

实例

<p>我会显示 &pound;</p>
<p>我会显示 &#163;</p>
<p>我会显示 &#x00A3;</p>

将显示为：

我会显示 £
我会显示 £
我会显示 £

C1 控制字符

控制字符最初被设计为控制硬件设备。

不应在 HTML 中显示控制字符。

但是，由于它们被定义为字符，因此在 Windows 使用的 ANSI 字符集中，如果您使用 Windows，则可能会显示它们。
