UTF-8 块元素

  • 箱型图
  • 几何形状

范围：十进制 9600-9631，十六进制 2580-259F

如果您希望在 HTML 中显示特殊字符，可以使用下表中的 HTML 实体。

如果字符没有 HTML 实体，则可以使用十进制（dec）或十六进制（hex）引用。

实例

<p>我会显示 &#9602;</p>
<p>我会显示 &#x2582;</p>

将显示为：

我会显示 ▂
我会显示 ▂
