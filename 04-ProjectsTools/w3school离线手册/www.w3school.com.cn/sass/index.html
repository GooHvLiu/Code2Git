Sass 是一种 CSS 预处理器。

Sass 减少了对 CSS 的重复，从而节省了时间。

每个章节中均提供实例

Sass 实例

/* 为网站定义标准变量和值 */
$bgcolor: lightblue;
$textcolor: darkblue;
$fontsize: 18px;

/* 使用变量 */
body {
  background-color: $bgcolor;
  color: $textcolor;
  font-size: $fontsize;
}
