AND

& 符号（和）是逻辑运算符，用于组合条件语句：

实例

测试 a 是否大于 b，并且 c 是否大于 a：

a <- 200
b <- 33
c <- 500

if (a > b & c > a) {
  print("两个条件都为真")
}

OR

| 符号（或）是一个逻辑运算符，用于组合条件语句：

实例

测试 a 是否大于 b，或者 c 是否大于 a：

a <- 200
b <- 33
c <- 500

if (a > b | a > c) {
  print("至少有一个条件为真")
}
