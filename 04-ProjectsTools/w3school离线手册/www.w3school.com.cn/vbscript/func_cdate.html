VBScript CDate 函数

VBScript 函数参考手册

定义和用法

CDate 函数可把一个合法的日期和时间表达式转换为 Date 类型，并返回结果。

提示：请使用 IsDate 函数来判断 date 是否可被转换为日期或时间。

注释：IsDate 函数使用本地设置来检测字符串是否可被转换为日期。

语法

CDate(date)
参数 描述
date 必需的。任何有效的日期表达式。（比如 Date() 或者 Now()）

实例

例子 1

d="April 22, 2001"
if IsDate(d) then
  document.write(CDate(d))
end if

输出：

2/22/01

例子 2

d=#2/22/01#
if IsDate(d) then
  document.write(CDate(d))
end if

输出：

2/22/01

例子 3

d="3:18:40 AM"
if IsDate(d) then
  document.write(CDate(d))
end if

输出：

3:18:40 AM
