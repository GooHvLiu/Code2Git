Pandas DataFrame ne() 方法

DataFrame 参考手册

定义和用法

ne() 方法会比较 DataFrame 中的每个值，以检查它是否不等于指定的值，或者是否不等于指定的 DataFrame 对象中的值，并为每个比较返回包含布尔值 True/False 的 DataFrame。

实例

找出哪些值不等于 7：

import pandas as pd

df = pd.DataFrame([[10, 12, 2], [3, 4, 7]])

print(df.ne(7))

亲自试一试

语法

dataframe.ne(other, axis, level)

参数

参数 描述
other 必需。数字、数字列表或与原始 DataFrame 结构相匹配的其他对象。
axis

可选。定义是按索引还是按列进行比较的定义。

  • 0 或 'index' 表示按索引进行比较
  • 1 或 'columns' 表示按列进行比较
level 可选。指示比较位置的数字或标签。

返回值

DataFrame 对象。
