Pandas DataFrame assign() 方法

DataFrame 参考手册

定义和用法

allocate() 方法向现有 DataFrame 添加新列。

实例

向 DataFrame 添加新列：

import pandas as pd

data = {
  "age": [16, 14, 10],
  "qualified": [True, True, True]
}
df = pd.DataFrame(data)

newdf = df.assign(name = ["Emil", "Tobias", "Linus"])

亲自试一试

语法

dataframe.assign(kwargs)

参数

参数 描述
kwargs 必需。带有值的新列名称。

返回值

添加了新列的 DataFrame。

该方法不会改变原始的DataFrame。
