Pandas DataFrame truediv() 方法

DataFrame 参考手册

定义和用法

truediv() 方法将 DataFrame 中的每个值除以指定值。

指定的值必须是一个可以与 DataFrame 中的值进行除法运算的对象。它可以是像示例中的常数，也可以是类似列表的对象，如列表 [10, 20] 或元组 {"points": 10, "total": 20}，或者是与原始 DataFrame 相匹配的 Pandas Series 或另一个 DataFrame。

实例

将 DataFrame 中的每个值除以 10：

import pandas as pd

data = {
  "points": [100, 120, 114],
  "total": [350, 340, 402]
}

df = pd.DataFrame(data)

print(df.truediv(10))

亲自试一试

语法

dataframe.truediv(other, axis, level, fill_value)

参数

参数 描述
other 必需。数字、数字列表，或另一个与原始 DataFrame 数据结构相匹配的对象。
axis

可选。定义是按索引还是按列进行比较的定义。

  • 0 或 'index' 表示按索引进行比较
  • 1 或 'columns' 表示按列进行比较
level 可选。指示比较位置的数字或标签。
fill_value 可选。数字，或 None。指定除法之前如何处理 NaN 值。

返回值

包含结果的 DataFrame。
