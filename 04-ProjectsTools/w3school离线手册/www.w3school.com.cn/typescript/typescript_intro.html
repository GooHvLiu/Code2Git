TypeScript 简介

  • TS 教程
  • TS 入门

TypeScript 是增加了类型语法的 JavaScript。

什么是 TypeScript？

TypeScript 是 JavaScript 的一个语法超集，它添加了静态类型。

这基本上意味着 TypeScript 在 JavaScript 的基础上增加了语法，允许开发人员添加类型。

TypeScript 作为“语法超集”意味着它与 JavaScript 共享相同的基础语法，但在此基础上增加了一些内容。

我为什么要使用 TypeScript？

JavaScript 是一种弱类型语言。在 JavaScript 中，很难理解传递的是哪种类型的数据。

在 JavaScript 中，函数参数和变量没有任何信息！因此，开发人员需要查看文档，或者根据实现进行猜测。

TypeScript 允许在代码中指定传递的数据类型，并在类型不匹配时报告错误。

例如，当向期望数字的函数传递字符串时，TypeScript 会报告错误。而 JavaScript 则不会。

TypeScript 使用编译时类型检查。这意味着它会在运行代码之前检查指定的类型是否匹配，而不是在运行代码时检查。

我如何使用 TypeScript？

使用 TypeScript 的一种常见方法是使用官方的 TypeScript 编译器，它将 TypeScript 代码转换为 JavaScript。
