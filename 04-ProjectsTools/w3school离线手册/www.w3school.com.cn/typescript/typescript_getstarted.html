TypeScript 编译器

TypeScript 使用编译器转换为 JavaScript。

TypeScript 转换为 JavaScript 意味着它可以在任何运行 JavaScript 的地方运行！

安装编译器

TypeScript 有一个官方编译器，可以通过 npm 安装。

在您的 npm 项目中，运行以下命令来安装编译器：

npm install typescript --save-dev

应该会给出类似的输出：

added 1 package, and audited 2 packages in 2s
found 0 vulnerabilities

编译器安装在 node_modules 目录中，可以使用以下命令运行：npx tsc。

npx tsc

应该会给出类似的输出：

Version 4.5.5
tsc: The TypeScript Compiler - Version 4.5.5

后面是所有常用命令的列表。

配置编译器

默认情况下，如果在一个空项目中运行，TypeScript 编译器将打印一条帮助消息。

可以使用 tsconfig.json 文件配置编译器。

您可以使用以下命令让 TypeScript 创建具有推荐设置的 tsconfig.json：

npx tsc --init

应该会给出类似的输出：

Created a new tsconfig.json with:
TS
  target: es2016
  module: commonjs
  strict: true
  esModuleInterop: true
  skipLibCheck: true
  forceConsistentCasingInFileNames: true

You can learn more at https://aka.ms/tsconfig.json

例如，以下是您可以添加到 tsconfig.json 文件的更多内容：

{
  "include": ["src"],
  "compilerOptions": {
    "outDir": "./build"
  }
}

您可以在编辑器中打开文件以添加这些选项。这将配置 TypeScript 编译器，将位于项目 src/ 目录中的 TypeScript 文件转译为 build/ 目录中的 JavaScript 文件。

这是快速入门 TypeScript 的一种方法。还有许多其他选项可用，例如 create-react-app 模板、node 入门项目和 webpack 插件。
