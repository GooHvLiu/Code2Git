什么是 C#？

C# 发音为 "C-Sharp"。

它是由 Microsoft 创建的一种面向对象的编程语言，在 .NET Framework 上运行。

C# 源自 C 语言家族，并且该语言与其他流行的语言（如 C++ 和 Java ）非常接近。

第一个版本发布于 2002 年。最新版本 C# 12 发布于 2023 年 11 月。

C# 用于：

  • 移动应用
  • 桌面应用
  • Web 应用
  • Web 服务
  • 网站
  • 游戏
  • VR
  • 数据库应用
  • 以及更多！

为什么使用 C#？

  • 它是世界上最流行的编程语言之一
  • 它易于学习和使用
  • 它拥有庞大的社区支持
  • C# 是一种面向对象的语言，为程序提供了清晰的结构，并允许重用代码，降低了开发成本
  • 由于 C# 与 C、C++ 和 Java 非常接近，因此程序员可以轻松地切换到C#，反之亦然
