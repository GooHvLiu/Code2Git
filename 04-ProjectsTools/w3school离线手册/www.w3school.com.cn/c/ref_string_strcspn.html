C string strcspn() 函数

C string 库

定义和用法

strcspn() 函数在字符串中搜索指定字符集的第一次出现，并返回到该点为止的字符串长度。如果未找到任何指定字符，则返回字符串的全长。

strcspn() 函数定义在 <string.h> 头文件中。

实例

测量字符串到第一个标点符号的长度：

char myStr[] = "Learn C++, Java and Python!";
int pos = strcspn(myStr, ",.!?");
printf("%d", pos);

亲自试一试

语法

strcspn(void * str, void * search);

参数

参数 描述
str 必需。要搜索的字符串。
search 必需。包含要搜索的字符集的字符串。

技术细节

返回：

整数，指示任何搜索字符第一次出现的位置。

如果未找到任何字符，则返回字符串的长度。
