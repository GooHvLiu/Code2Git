Python 教程

Python 是一门流行的编程语言。它由 Guido van Rossum 创建，于 1991 年发布。

它可用于 Web 开发（服务器端）、软件开发、数学、系统脚本。

Python DSA

数据结构探讨的是如何将数据以不同的结构进行存储。

算法则关注如何解决各种问题，通常是通过遍历和操作数据结构来实现。

掌握数据结构与算法能帮助您找到最优的数据结构与算法组合，从而编写更高效的代码。

NumPy

NumPy 是一个 Python 库。

NumPy 用于处理数组。

NumPy 是 "Numerical Python" 的缩写。

现在就开始学习 NumPy

Pandas

Pandas 是一个 Python 库。

Pandas 用于分析数据。

现在就开始学习 Pandas

SciPy

SciPy 是一个科学计算库，底层使用了 NumPy。

SciPy 指的是 Scientific Python。

现在就开始学习 SciPy

Matplotlib

Matplotlib 是一个 Python 中的低级图形绘制库，用作可视化工具。

Matplotlib 是由 John D. Hunter 创建的。

Matplotlib 是开源的，我们可以自由使用它。

Matplotlib 主要用 Python 编写，为了平台兼容性，少数部分用 C、Objective-C 和 Javascript 编写。

现在就开始学习 Matplotlib

C

C 是一种通用的编程语言，于 1972 年开发，至今仍然相当流行。

C 语言功能非常强大，已被用于开发操作系统、数据库、应用程序等。

现在就开始学习 C

C++

C++ 是一种流行的编程语言。

C++ 用于创建计算机程序，并且是游戏开发中最常用的语言之一。

C++ 是作为 C 语言 的扩展而开发的，这两种语言的语法几乎相同。

现在就开始学习 C++

R

R 是一种编程语言。

R 经常用于统计计算和图形表示，以分析和可视化数据。

现在就开始学习 R

Go

Go 是一种流行的编程语言。

Go 用于创建计算机程序。

现在就开始学习 Go

Kotlin

Kotlin 是一种现代、流行的编程语言。

Kotlin 很容易学习，特别是如果您已经了解 Java（它与 Java 100% 兼容）。

Kotlin 用于开发 Android 应用程序、服务器端应用程序等等。
