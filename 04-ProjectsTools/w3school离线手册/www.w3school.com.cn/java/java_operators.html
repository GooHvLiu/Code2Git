Java 运算符

运算符用于对变量和值执行操作。

在下面的例子中，我们使用 + 运算符将两个值相加：

实例

int x = 100 + 50;

亲自试一试

尽管 + 运算符经常用于将两个值相加，就像上面的例子一样，但它也可以用于将一个变量和一个值相加，或者将一个变量和另一个变量相加：

实例

int sum1 = 100 + 50;        // 150 (100 + 50)
int sum2 = sum1 + 250;      // 400 (150 + 250)
int sum3 = sum2 + sum2;     // 800 (400 + 400)

Java 将运算符分为以下几组：

  • 算术运算符

Java 赋值运算符

赋值运算符用于为变量赋值。

在下例中，我们使用赋值运算符 (=) 将值 10 分配给名为 x 的变量：

实例

int x = 10;

加法赋值运算符 (+=) 向变量加一个值：

Java 比较运算符

比较运算符用于比较两个值（或变量）。这在编程中很重要，因为它可以帮助我们找到答案并做出决策。

比较的返回值为 true 或 false。这些值被称为布尔值，您可以在数据类型和 If..Else 章节中学到更多相关内容。

在下面的例子中，我们使用大于运算符 (>) 来判断 5 是否大于 3：

实例

int x = 5;
int y = 3;
System.out.println(x > y); // 返回 true，因为 5 大于 3

Java 逻辑运算符

您还可以使用逻辑运算符测试 true 或 false 值。

逻辑运算符用于确定变量或值之间的逻辑：

运算符 名称 描述 例子 试一试
&& 逻辑和 如果两条语句都为真，则返回 true。 x < 5 && x < 10 试一试
|| 逻辑或 如果其中一条语句为真，则返回 true。 x < 5 || x < 4 试一试
! 逻辑否 反转结果。如果结果为真，则返回 false。 !(x < 5 && x < 10) 试一试
