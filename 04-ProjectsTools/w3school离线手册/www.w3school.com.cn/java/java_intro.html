什么是 Java？

Java 是一门流行的编程语言，创始于 1995 年。

它归 Oracle 所有，有超过 30 亿台设备在运行 Java。

它可用于：

  • 移动 APP（尤其是 Android 应用程序）
  • 桌面 APP
  • Web APP
  • Web 服务器和应用程序服务器
  • 游戏
  • 数据库连接
  • 还有很多其他应用领域！

为什么要使用 Java？

  • 适用于不同的平台（Windows、Mac、Linux、Raspberry Pi 等）
  • 世界上最流行的编程语言之一
  • 易学、易用
  • 开源、免费
  • 安全、快速且功能强大
  • 拥有庞大的社区支持（数千万开发者）
  • 面向对象，为程序提供了清晰的结构并允许代码重用，从而降低开发成本
  • 由于语法相近，C++ 和 C# 程序员可以轻松切换到 Java，反之亦然

学习 Java 之前，需要具备的基础知识

您不需要拥有任何先前的编程经验。
