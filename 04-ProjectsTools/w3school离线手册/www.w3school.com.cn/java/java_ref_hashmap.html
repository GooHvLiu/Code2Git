HashMap 的所有方法

以下表格列出了 HashMap 的所有方法。

部分方法使用 HashMap 条目的类型作为参数或返回值。在表格中，键的类型将被称作 K，值的类型将被称作 V。

方法 描述 返回类型
clear() 从映射中移除所有条目。 void
clone() 创建 HashMap 的副本。 Object
compute() 基于条目的键和当前值（如果有）计算该条目的值。 V
computeIfAbsent() 如果使用给定键的条目不存在，则基于键计算该条目的值。 V
computeIfPresent() 基于键和当前值计算该条目的新值 V
containsKey() 指示映射中是否存在具有指定键的条目。 boolean
containsValue() 指示映射中是否存在具有指定值的条目。 boolean
entrySet() 返回映射中所有条目的集合。 Set< Map.Entry<K,V> >
forEach() 对映射中的每个条目执行一个操作。 void
get() 返回具有指定键的条目的值。 V
getOrDefault() 返回具有指定键的条目的值，如果条目不存在则返回默认值。 V
isEmpty() 指示映射是否为空。 boolean
keySet() 返回映射中所有键的集合。 Set<K>
merge() 基于条目的键和值计算该条目的值。 V
put() 将条目写入映射中。 V
putAll() 将另一个映射中的所有条目写入此映射中。 void
putIfAbsent() 仅当不存在具有相同键的条目时，才将条目写入映射中。 V
remove() 从映射中移除条目。 V|boolean
replace() 仅当条目存在时，才向映射中的条目写入值。 V|boolean
replaceAll() 用操作的结果替换每个条目的值。 void
size() 返回映射中条目的数量。 int
values() 返回包含映射中所有值的集合。 Collection<V>
