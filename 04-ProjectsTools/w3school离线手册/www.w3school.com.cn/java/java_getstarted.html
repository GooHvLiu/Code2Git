Java 安装

一些 PC 可能已经安装了 Java。

如需检查您是否在 Windows PC 上安装了 Java，请在开始栏中搜索 Java 或在命令提示符 (cmd.exe) 中键入以下内容：

C:\Users\Your Name>java -version

如果已安装 Java，您将看到如下内容（取决于版本）：

java version "11.0.1" 2018-10-16 LTS
Java(TM) SE Runtime Environment 18.9 (build 11.0.1+13-LTS)
Java HotSpot(TM) 64-Bit Server VM 18.9 (build 11.0.1+13-LTS, mixed mode)

如果您的计算机上还没有安装 Java，可以从 oracle.com 免费下载：

  1. 以 Windows 操作系统为例，建议您下载 x64 Installer 或 x64 MSI Installer 安装文件
  2. 执行安装文件，并设置安装目录，完成安装

提示：在本教程中，我们将在文本编辑器中编写 Java 代码。但是，可以在集成开发环境（例如 IntelliJ IDEA、Netbeans 或 Eclipse）中编写 Java，这有助于帮助您管理较大的 Java 文件集。

Windows 设置

在 Windows 上安装 Java：

  1. 打开“Windows 设置”，并点击“系统”
  2. 点击“关于”，点击“高级系统设置”，打开“系统属性”
  3. 单击“高级”选项卡下的“环境变量”按钮
  4. 然后，在系统变量中选择“Path”变量并点击“编辑”按钮
  5. 点击“新建”按钮，添加 Java 的安装路径，后跟 \bin。单击“确定”，并保存设置
  6. 最后，打开命令提示符（cmd.exe）并输入 java -version 以查看 Java 是否能在您的机器上运行

注释：以 Java21 为例，在默认情况下，Java 安装在 C:\Program Files\Java\jdk-21。在这种情况下，您需要添加的新路径是：C:\Program Files\Java\jdk-11.0.1\bin。

请在命令行（cmd.exe）中键入以下内容：

C:\Users\Your Name>java -version

如果 Java 安装成功，您将看到如下内容（取决于版本）：

java version "11.0.1" 2018-10-16 LTS
Java(TM) SE Runtime Environment 18.9 (build 11.0.1+13-LTS)
Java HotSpot(TM) 64-Bit Server VM 18.9 (build 11.0.1+13-LTS, mixed mode)

Java 快速入门

在 Java 中，每个应用程序都以类名开头，并且该类必须与文件名匹配。

让我们创建第一个 Java 文件，名为 Main.java。我们可以在任何文本编辑器（如记事本）中编写。

这个文件可打印 "Hello World" 消息，该消息使用以下代码编写：

Main.java

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

亲自试一试

如果您不理解上面的代码，请不要担心 - 我们将在后面的章节中详细讨论。现在，请专注于如何运行上面的代码。

请将记事本中的代码保存为 "Main.java"。打开命令提示符 (cmd.exe)，导航到保存文件的目录，然后键入 "javac Main.java"：

C:\Users\Your Name>javac Main.java

这么做会编译您的代码。如果代码中没有错误，命令提示符将带您到下一行。现在，输入 "java Main" 来运行文件：

C:\Users\Your Name>java Main

输出将是：

Hello World

亲自试一试

恭喜！您已经编写并执行了您的第一个 Java 程序。
