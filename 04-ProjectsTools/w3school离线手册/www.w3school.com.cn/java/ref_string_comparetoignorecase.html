Java String compareToIgnoreCase() 方法

Java String 方法

定义和用法

compareToIgnoreCase() 方法按字典顺序比较两个字符串，忽略小写和大写差异。

比较基于字符串中每个字符转换为小写的 Unicode 值。

  • 如果该字符串与另一个字符串相等，则该方法返回 0，忽略大小写差异。
  • 如果该字符串小于另一个字符串（字符数较少），则返回小于 0 的值。
  • 如果该字符串大于另一个字符串（字符较多），则返回大于 0 的值。

实例

比较两个字符串，忽略小写和大写差异：

String myStr1 = "HELLO";
String myStr2 = "hello";
System.out.println(myStr1.compareToIgnoreCase(myStr2));

亲自试一试

语法

public int compareToIgnoreCase(String string2)

参数

参数 描述
string2 String，代表要比较的另一个字符串。

技术细节

返回：

0：如果字符串与另一个字符串相等，忽略大小写差异。

< 0 如果该字符串按字典顺序小于另一个字符串。

> 0 如果该字符串按字典顺序大于另一个字符串（更多字符）。
Java 版本： 1.2
