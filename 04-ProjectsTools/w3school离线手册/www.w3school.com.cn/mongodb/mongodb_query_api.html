MongoDB 查询 API

MongoDB 查询 API 是您与数据进行交互的方式。

MongoDB 查询 API 可以通过两种方式使用：

  • CRUD 操作
  • 聚合管道

MongoDB 查询 API 的用途

您可以使用 MongoDB 查询 API 执行以下操作：

  • 使用 mongosh、Compass、VS Code 或您使用的编程语言的 MongoDB 驱动程序执行临时查询。
  • 使用聚合管道进行数据转换。
  • 文档连接支持，以合并来自不同集合的数据。
  • 图形和地理空间查询。
  • 全文搜索。
  • 索引以提高 MongoDB 查询性能。
  • 时间序列分析。
