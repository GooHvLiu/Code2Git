MongoDB Charts

MongoDB Charts 允许您以简单、直观的方式可视化您的数据。

MongoDB Charts 设置

从 MongoDB Atlas 仪表板，转到 Charts 选项卡。

如果您从未使用过 Charts，请点击 Activate Now 按钮。这将需要大约 1 分钟来完成。

您将看到一个新的仪表板。点击仪表板名称以打开它。

创建图表

通过点击 Add Chart 按钮来创建新图表。

直观地创建图表很简单。选择您要使用的数据源。

举例：

在此例中，我们使用的是在聚合章节中从示例数据中加载的 "sample_mflix" 数据库。

在 Data Source 下，选择 Movies 集合。

让我们可视化每年发行了多少部电影。

将 Year 字段拖到 Y Axis 字段，并将 Bin Size 设置为 1。

将 _id 字段拖到 X Axis 字段，并确保为 Aggregate 选择了 COUNT。

现在，您应该能看到一个条形图，显示每年发行的电影数量。
