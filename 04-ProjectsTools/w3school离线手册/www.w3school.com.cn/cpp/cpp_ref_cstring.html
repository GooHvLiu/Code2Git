C++ cstring 函数

<cstring> 库包含许多函数，可用于操作数组和 C 风格字符串。

注意：C 风格字符串与常规字符串不同。C 风格字符串是由 char 类型创建的字符数组。

如需了解更多关于 C 风格字符串的信息，请学习我们的 C 字符串教程。

所有 cstring 函数的列表，可在下表中找到。

函数 描述
memchr() 返回指向内存块中首次出现某个值的指针。
memcmp() 比较两个内存块以确定哪个代表更大的数值。
memcpy() 将数据从一个内存块复制到另一个内存块。
memmove() 将数据从一个内存块复制到另一个内存块，考虑内存块可能重叠的情况。
memset() 将内存块中的所有字节设置为相同的值。
strcat() 将一个 C 风格字符串追加到另一个字符串的末尾。
strchr() 返回指向 C 风格字符串中首次出现某个字符的指针。
strcmp() 比较两个 C 风格字符串中字符的 ASCII 值以确定哪个字符串具有更高的值。
strcoll() 基于区域设置比较两个 C 风格字符串中字符的值以确定哪个字符串具有更高的值。
strcpy() 将 C 风格字符串的字符复制到另一个字符串的内存中。
strcspn() 返回 C 风格字符串中首次出现指定字符之一的长度。
strerror() 返回描述错误代码含义的 C 风格字符串。
strlen() 返回 C 风格字符串的长度。
strncat() 将 C 风格字符串中的指定数量字符追加到另一个字符串的末尾。
strncmp() 比较两个 C 风格字符串中指定数量字符的 ASCII 值以确定哪个字符串具有更高的值。
strncpy() 将 C 风格字符串中的指定数量字符复制到另一个字符串的内存中。
strpbrk() 返回指向 C 风格字符串中包含指定字符之一的第一个位置的指针。
strrchr() 返回指向 C 风格字符串中最后一次出现某个字符的指针。
strspn() 返回 C 风格字符串中不包含指定字符的第一个字符之前的长度。
strstr() 返回指向另一个字符串中首次出现 C 风格字符串的指针。
strtok() 使用分隔符将字符串分割成多个部分。
strxfrm() 将 C 风格字符串中的字符从 ASCII 编码转换为当前区域设置的编码。
