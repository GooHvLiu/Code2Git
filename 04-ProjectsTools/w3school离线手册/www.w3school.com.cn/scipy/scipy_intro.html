什么是 SciPy？

SciPy 是一个科学计算库，底层使用了 NumPy。

SciPy 代表科学 Python。

它提供了更多的实用函数，用于优化、统计和信号处理。

与 NumPy 一样，SciPy 是开源的，因此我们可以自由使用。

SciPy 是由 NumPy 的创造者 Travis Olliphant 创建的。

为什么要使用 SciPy？

如果 SciPy 在底层使用了 NumPy，那我们为什么不能只使用 NumPy 呢？

SciPy 对 NumPy 和数据科学中经常使用的函数进行了优化和增补。

SciPy 是用哪种语言写的？

SciPy 主要是用 Python 写的，但有几个部分是用 C 写的。

SciPy 的代码库在哪里？

SciPy 的源代码位于 github 存储库中：https://github.com/scipy/scipy

github：允许多人在同一个代码库上工作。
