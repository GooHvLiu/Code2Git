SciPy 入门

  • SciPy 介绍
  • SciPy 常量

安装 SciPy

如果您的系统上已经安装了 Python 和 PIP，那么安装 SciPy 就很容易了。

使用以下命令来安装：

C:\Users\Your Name>pip install scipy

如果此命令失败，那么请使用已经安装了 SciPy 的 Python 发行版，如 Anaconda、Spyder 等。

导入 SciPy

安装 SciPy 后，通过添加这条语句语句，导入您想在应用程序中使用的 SciPy 模块：

from scipy import constants

现在，我们已经从 SciPy 导入了 constants 模块，应用程序已准备好使用它：

实例

一升等于多少立方米：

from scipy import constants

print(constants.liter)

亲自试一试

constants: SciPy提供了一组数学常数，其中之一是 liter，它以立方米返回 1 升。

您将在下一章中了解更多关于常量的信息。

检查 SciPy 版本

版本字符串存储在 __version__ 属性下。

实例

import scipy

print(scipy.__version__)

亲自试一试

注意：__version__ 中使用了两个下划线字符。
