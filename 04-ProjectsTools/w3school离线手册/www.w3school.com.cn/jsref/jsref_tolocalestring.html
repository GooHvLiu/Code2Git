JavaScript Date toLocaleString() 方法

  • toLocaleTimeString()
  • toString()
  • JavaScript Date 参考手册

定义和用法

toLocaleString() 方法使用区域设置将 Date 对象转换为字符串。

默认语言取决于您计算机上的区域设置。

实例

使用区域约定将 Date 对象转换为字符串：

var d = new Date();
var n = d.toLocaleString();

语法

Date.toLocaleString(locales, options)
