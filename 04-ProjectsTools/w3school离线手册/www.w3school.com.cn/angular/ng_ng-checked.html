AngularJS ng-checked 指令

AngularJS 参考手册

定义和用法

ng-checked 指令用于设置复选框或单选按钮的 checked 属性。

如果 ng-checked 属性中的表达式返回 true，则选中复选框或单选按钮。

ng-checked 指令对于在 true 和 false 之间切换值是必要的。在 HTML 中，您不能将 checked 属性设置为 false（checked 属性的存在会使元素被选中，无论其值如何）。

实例

勾选一个即可全选：

<body ng-app="">
<p>我的车：</p>
<input type="checkbox" ng-model="all"> 全选<br><br>

<input type="checkbox" ng-checked="all">Volvo<br>
<input type="checkbox" ng-checked="all">Ford<br>
<input type="checkbox" ng-checked="all">Mercedes
</body>

亲自试一试

语法

<input type="checkbox|radio" ng-checked="expression"></input>

由复选框或单选类型的 <input> 元素支持。

参数

参数 描述
expression 表达式，如果返回 true，则将设置元素的 checked 属性。
