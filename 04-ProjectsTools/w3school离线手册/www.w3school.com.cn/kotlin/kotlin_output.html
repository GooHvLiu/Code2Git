Kotlin 输出（打印）

println() 函数用于输出值/打印文本：

实例

fun main() {
  println("Hello World")
}

亲自试一试

您可以根据需要添加任意数量的 println() 函数。请注意，每个函数都会添加一个新行：

实例

fun main() {
  println("Hello World!")
  println("I am learning Kotlin.")
  println("It is awesome!")
}

亲自试一试

您也可以打印数字，并执行数学计算：

实例

fun main() {
  println(3 + 3)
}

亲自试一试

print() 函数

还有一个 print() 函数，它与 println() 类似。唯一的区别是它在输出的末尾不会插入新行：

实例

fun main() {
  print("Hello World! ")
  print("I am learning Kotlin. ")
  print("It is awesome!")
}

亲自试一试

提示：请注意，我们添加了一个空格字符以在句子之间创建空格。
