Kotlin 条件和 If..Else

Kotlin 支持数学中常见的逻辑条件：

  • 小于：a < b
  • 小于或等于：a <= b
  • 大于：a > b
  • 大于或等于：a >= b
  • 等于：a == b
  • 不等于：a != b

您可以使用这些条件来针对不同的决策执行不同的操作。

Kotlin 有以下条件语句：

  • 使用 if 来指定一个代码块，当满足一个指定的条件时执行
  • 使用 else 来指定一个代码块，在同一条件不满足时执行
  • 使用 else if 来指定一个新的条件进行测试，如果第一个条件不满足
  • 使用 when 来指定许多替代的代码块来执行

注意：与 Java 不同，Kotlin 中的 if..else 可以作为语句或表达式（为变量赋值）使用。请参见页面底部的实例来更好地理解它。

Kotlin if

使用 if 指定条件为 true 时要执行的代码块。

语法

if (condition) {
  // 如果条件为真，要执行的代码块
}

提示

请注意，if 是小写字母。大写字母（If 或 IF）将生成错误。

在下面的例子中，我们测试两个值以确定 20 是否大于 18。如果条件为真，则打印一些文本：

实例

if (20 > 18) {
  println("20 大于 18")
}

亲自试一试

我们还可以测试变量：

实例

val x = 20
val y = 18
if (x > y) {
  println("x 大于 y")
}

亲自试一试

例子解释

在上面的示例中，我们使用两个变量 x 和 y 来测试 x 是否大于 y（使用 > 运算符）。因为 x 是 20，y 是 18，并且我们知道 20 大于 18，所以我们在屏幕上打印“x 大于 y”。

Kotlin else

使用 else 指定条件为 false 时要执行的代码块。

语法

if (condition) {
  // 如果条件为真，要执行的代码块
} else {
  // 如果条件为假，要执行的代码块
}

实例

val time = 20
if (time < 18) {
  println("日安")
} else {
  println("晚安")
}
// 输出 "晚安"

亲自试一试

例子解释

在上面的实例中，时间 (20) 大于 18，因此条件为假，因此我们转到 else 条件并在屏幕上打印“晚安”。如果时间小于 18，程序将打印“日安”。

Kotlin else if

如果第一个条件为假，则使用 else if 指定新条件。

语法

if (condition1) {
  // 如果 condition1 为真，要执行的代码块
} else if (condition2) {
  // 如果 condition1 为假且 condition2 为真，要执行的代码块
} else {
  // 如果 condition1 和 condition2 都为假，要执行的代码块
}

实例

val time = 22
if (time < 10) {
  println("早安")
} else if (time < 20) {
  println("日安")
} else {
  println("晚安")
}
// 输出"晚安"

亲自试一试

例子解释

在上面的示例中，时间（22）大于 10，因此第一个条件为假。else if 语句中的下一个条件也为假，因此我们继续执行 else 条件（因为 condition1 和 condition2 都为假），并在屏幕上打印“晚安”。

Kotlin If..Else 表达式

在 Kotlin 中，您还可以使用 if..else 语句作为表达式（为变量赋值并返回它）：

实例

val time = 20
val greeting = if (time < 18) {
  "日安"
} else {
  "晚安"
}
println(greeting)

亲自试一试

提示：当 if 用作表达式时，您还必须包含 else（必需）。

注意：如果 if 只有一个语句，则可以省略花括号 {}：

实例

fun main() {
  val time = 20
  val greeting = if (time < 18) "Good day." else "Good evening."
  println(greeting)
}

亲自试一试

提示：此例类似于 Java 中的三元运算符（简写 if...else）。
