学习 Kotlin

Kotlin 是一种现代、流行的编程语言。

Kotlin 很容易学习，特别是如果您已经了解 Java（它与 Java 100% 兼容）。

Kotlin 用于开发 Android 应用程序、服务器端应用程序等等。
