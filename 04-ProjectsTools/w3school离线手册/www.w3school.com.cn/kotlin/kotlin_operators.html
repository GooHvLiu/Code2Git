Kotlin 运算符

运算符用于对变量和值执行操作。

该值被称为操作数，而两个操作数之间的操作是由运算符定义的：

操作数 运算符 操作数
100 + 50

在下面的例子中，数字 100 和 50 是操作数，+ 符号是运算符：

实例

var x = 100 + 50

亲自试一试

尽管 + 运算符经常用于将两个值相加，如上例所示，但它也可以用于将变量和值相加，或者变量和变量相加：

实例

var sum1 = 100 + 50       // 150 (100 + 50)
var sum2 = sum1 + 250     // 400 (150 + 250)
var sum3 = sum2 + sum2    // 800 (400 + 400)

亲自试一试

Kotlin 将运算符分为以下几组：

  • 算术运算符
  • 赋值运算符
  • 比较运算符
  • 逻辑运算符

Kotlin 赋值运算符

赋值运算符用于给变量赋值。

在下面的例子中，我们使用赋值运算符 (=) 将值 10 赋给名为 x 的变量：

实例

var x = 10

加法赋值运算符 (+=) 将值添加到变量：

实例

var x = 10
x += 5
