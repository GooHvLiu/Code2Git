Kotlin 布尔值

在编程中，很多时候你需要一个只能有两个值之一的数据类型，比如：

  • 是 / 否
  • 开 / 关
  • 真 / 假

为此，Kotlin 有一个布尔数据类型，它可以取值 true 或 false。

布尔值

布尔类型可以使用 Boolean 关键字声明，并且只能取值 true 或 false：

实例

val isKotlinFun: Boolean = true
val isFishTasty: Boolean = false
println(isKotlinFun)   // 输出 true
println(isFishTasty)   // 输出 false

亲自试一试

就像您在前面的章节中学习的其他数据类型一样，上面的例子也可以在不指定类型的情况下编写，因为 Kotlin 足够智能，可以理解这些变量是布尔值：

实例

val isKotlinFun = true
val isFishTasty = false
println(isKotlinFun)   // 输出 true
println(isFishTasty)   // 输出 false

亲自试一试

布尔表达式

布尔表达式返回布尔值：true 或 false。

您可以使用比较运算符，例如大于运算符 (>) 来确定表达式（或变量）是否为 true：

实例

val x = 10
val y = 9
println(x > y) // 返回 true，因为 10 大于 9

亲自试一试

或者更简单：

实例

println(10 > 9) // 返回 true，因为 10 大于 9

亲自试一试

在下面的例子中，我们使用等于运算符 (==) 来计算表达式：

实例

val x = 10;
println(x == 10); // 返回 true，因为 x 的值等于 10

亲自试一试

实例

println(10 == 15); // 返回 false，因为 10 不等于 15

亲自试一试
