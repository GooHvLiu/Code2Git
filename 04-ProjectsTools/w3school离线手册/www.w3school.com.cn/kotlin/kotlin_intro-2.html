什么是 Kotlin？

Kotlin 是一种现代流行编程语言，由 JetBrains 于 2016 年发布。

它变得非常流行，因为它与 Java（最流行的编程语言之一）兼容，这意味着 Java 代码（和库）可以在 Kotlin 程序中使用。

Kotlin 用于：

  • 移动应用程序（特别是 Android 应用程序）
  • Web 开发
  • 服务器端应用程序
  • 数据科学
  • 还有很多很多！

为什么要使用 Kotlin？

  • Kotlin 与 Java 完全兼容
  • Kotlin 可在不同的平台（Windows、Mac、Linux、Raspberry Pi 等）上运行
  • Kotlin 简洁且安全
  • Kotlin 很容易学习，特别是如果你已经知道 Java
  • Kotlin 可免费使用
  • 拥有庞大的社区/支持
