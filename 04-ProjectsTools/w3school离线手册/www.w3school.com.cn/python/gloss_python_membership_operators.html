Python 成员运算符

成员运算符用于测试序列是否出现在对象中：

运算符 例子 等同于 试一试
in 如果包含指定值的序列在对象中存在，则返回 True。 x in y 亲自试一试
not in 如果包含指定值的序列在对象中不存在，则返回 True。 x not in y 亲自试一试
