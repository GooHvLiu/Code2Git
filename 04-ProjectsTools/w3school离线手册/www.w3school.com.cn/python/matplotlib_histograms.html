直方图

直方图是一种显示频率分布的图形。

它显示每个给定区间内的观测值的数量。

举例：假设您询问了 250 个人的身高，您可能会得到一个如下的直方图：

从直方图中可以读取到：

身高在 140 到 145cm 之间的大约有 2 人
身高在 145 到 150cm 之间的大约有 5 人
身高在 151 到 156cm 之间的大约有 15 人
身高在 157 到 162cm 之间的大约有 31 人
身高在 163 到 168cm 之间的大约有 46 人
身高在 168 到 173cm 之间的大约有 53人
身高在 173 到 178cm 之间的大约有 45人
身高在 179 到 184cm 之间的大约有 28人
身高在 185 到 190cm 之间的大约有 21人
身高在 190 到 195cm 之间的大约有 4人

创建直方图

在 Matplotlib 中，我们使用 hist() 函数来创建直方图。

hist() 函数将使用一组数字来创建直方图，这组数字作为参数发送到函数中。

为了简化，我们使用 NumPy 随机生成一个包含 250 个值的数组，其中值将集中在 170 附近，标准差为 10。请在我们的机器学习教程中学习更多关于正态数据分布的知识。

实例

NumPy 生成的正态数据分布：

import numpy as np

x = np.random.normal(170, 10, 250)

print(x)

hist() 函数将读取数组并生成一个直方图：

实例

一个简单的直方图：

import matplotlib.pyplot as plt
import numpy as np

x = np.random.normal(170, 10, 250)

plt.hist(x)
plt.show()
