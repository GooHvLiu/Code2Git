###### 数据传递

首先在App.vue中创建一个数据向子传递和创建一个方法传递给子组件，具体实现如下：

App.vue的源码如下：

```vue
<template>
  <div id="app">
    <div class="todo-page">
      <div class="todo-container">
        <UserHeader :addTodo="addTodo" />
        <UserLists :todos="todos" />

      </div>
    </div>
  </div>
</template>
<script>
import UserHeader from "./components/UserHeader";
import UserFooter from "./components/UserFooter";
import UserLists from "./components/UserLists";
export default {
  name: "App",
  components: {UserHeader,UserFooter,UserLists},
  data() {return { todos: [{ id: "001", title: "抽烟", done: true },{ id: "002", title: "喝酒", done: true },{ id: "003", title: "烫头", done: true },{ id: "004", title: "开车", done: false } ]};
  },
  methods:{addTodo(todoObj){if (!todoObj){alert("输入数据不能为空"); return;}this.todos.unshift(todoObj); } }
};
</script>
```

> 1. addTodo方法传递给子组件，用于将创建的待完成事项传递回来
>
> 2. todos是所有待完成事项的模拟数据数组

UserHeader.vue的源码如下：

```vue
<template>
  <!-- 头部显示 -->
  <div class="todo-header">
    <input type="text" placeholder="请输入您的任务名称，按回车确认"  v-model="title"  @keyup.enter="add" />
  </div>
</template>
<script>
import { nanoid } from "nanoid";
export default {
  name: "UserHeader",
  data() {return {title: ""};},
  methods: {
    //当用户点击enter键之后，进入此方式的执行
    add() {
      if (!this.title.trim()) return;
      //创建数据对象todoObj
      const todoObj = { id: nanoid(), title: this.title, done: false };
      //使用父组件传递过来的方法实现数据的子传父功能
      this.addTodo(todoObj);
      //清空显示框数据
      this.title = "";
    }
  },
  props: ["addTodo"]
};
</script>
```

> add方法实际是用户点击回车触发的添加事件，然后对父组件传递过来的addTodo进行实现

}

###### 数据统计

在通过人机交互后，可以实时显示一共多少条数据和当前已经被选中的条数，在UserFooter.vue：

```vue
<template>
...
    <span> <span>已完成 {{ isDoneCounts }} 条</span> /共 {{ TotalCounts }} 条</span >
...
</template>
<script>
...
computed: {
    //计算当前一共多少条待办事项
    TotalCounts() {  return this.todos.length;  },
    //计算当前一共多少条已完成待办事项
    isDoneCounts() {let todoCounts = 0;this.todos.forEach((todo) => {if (todo.done) {todoCounts++;}});
      return todoCounts;}},
  props: ["todos"]
};
</script>
```

> 通过计算属性实现实时显示

#### 本地存储

本地存储实现在代码中无需存放数据，通过添加的方式实现将数据存储在本地，主要在App.vue中使用localStorage的setItem和getItem实现存储和读取：

```javascript
...
data() {
    return {
      //初始化时，从本地存储中读取数据
      todos: JSON.parse(localStorage.getItem("todos")) || []
    };
  },
  watch: {
    /* //将用户输入数据存储在本地，使用本地存储方案，浅层监视无法实现监视对象内部属性
    todos(newvalue) {
      localStorage.setItem("todos", JSON.stringify(newvalue));
    } */
    //将用户输入数据存储在本地，使用本地存储方案，深度监视实现监视对象内部属性
    todos: {
      deep: true,
      handler(value) {
        localStorage.setItem("todos", JSON.stringify(value));
      }
    }
  }
...
```

#### 全局总线

全局事件总线适用于兄弟间数据传递、孙与爷组件数据传递，所以，此次我们针对App.vue和UserItem.vue之间的数据传递：

##### 创建事件

在main.js文件中创建vm/vc身上的\$bus总线：

```js
import Vue from "vue";
import App from "./App.vue";

Vue.config.productionTip = false;

new Vue({
  render: (h) => h(App),
  // 如下为创建全局数据总线,全局的VC和VM都能具有此方法$bus及对应的$on、$off、$emit
  beforeCreate() {
    Vue.prototype.$bus = this;
  }
}).$mount("#app");

```

##### 发送数据

在发送数据的组件UserItem.vue上，通过\$bus.\$emit进行自定义事件绑定，并将数据发过去：

```vue
<script>
export default {
  name: "UserItem",
  methods: {
    isChecked(todoId) {
      this.$bus.$emit("isCheckedOrNot", todoId);
    },
    deleteTodo(todoId) {
      if (confirm("确定要删除么？")) {
        this.$bus.$emit("isDeletedTodo", todoId);
      }
    }
  },
  props: ["todo"]
};
</script>
```

> UserItem.vue是数据发送方，通过\$bus.\$emit进行自定义事件绑定

##### 接收数据

在接收数据的组件App.vue上，通过\$bus.\$on进行自定义事件创建，并将数据接收过来，并将原始通过UserLists.vue传递数据的方法删除：

```vue
<template>
  <div id="app">
    ...
    <UserLists :todos="todos" />
    ...
  </div>
</template>
<script>
...
  //通过创建自定义事件，实现总线通讯
  mounted() {
    this.$bus.$on("isCheckedOrNot", this.isCheckedOrNot);
    this.$bus.$on("isDeletedTodo", this.isDeletedTodo);
  }
};
</script>
```

> UserLists.vue中的数据接收到传递都需要删除，再次不再赘述

##### 注销总线

本着谁创建谁注销的原则，在App.vue组件中对全局总线进行注销

```vue
  //通过创建自定义事件，实现总线通讯
  mounted() {
    this.$bus.$on("isCheckedOrNot", this.isCheckedOrNot);
    this.$bus.$on("isDeletedTodo", this.isDeletedTodo);
  },
  //在创建组件销毁前进行注销全局总线
  beforeDestroy() {
    this.$bus.$off("isCheckedOrNot");
    this.$bus.$off("isDeletedTodo");
  }
```
