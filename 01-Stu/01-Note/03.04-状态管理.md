# 03.04 状态管理

## Pinia

### 基础入门

#### 基本特点

##### 基本定义

Pinia 是 Vue.js 的官方状态管理库，由 Vue 核心团队成员开发，是 Vuex 的继任者。

##### 核心特点

- 直观的 API，像写普通组件一样写 Store
- 完整的 TypeScript 支持
- 支持 Vue 2 和 Vue 3
- 模块化设计，自动代码分割
- 极轻量（约 1KB）
- 支持 DevTools、时间旅行调试
- 没有 mutations，Actions 即可同步也可异步

##### 核心优势

| 特性       | Vuex 3/4                                        | Pinia 2                   |
| ---------- | ----------------------------------------------- | ------------------------- |
| mutations  | 必须有，用于同步修改                            | 已移除，直接修改 state    |
| TypeScript | 支持较弱，类型推导复杂                          | 原生支持，类型推导完善    |
| 模块化     | 需要嵌套 modules                                | 扁平结构，每个 Store 独立 |
| 组合式 API | 支持一般                                        | 完美支持                  |
| 学习曲线   | 较陡（state/mutations/actions/getters/modules） | 平缓                      |
| 体积       | 较大                                            | ~1KB                      |
| DevTools   | 支持                                            | 支持，含时间旅行          |

**一句话总结**：Pinia = Vuex 的能力 + 更简单的 API + 更好的 TS 支持。

#### 书写方式

##### 选项式

```ts
// src/stores/counter.ts Options API 风格
import { defineStore } from "pinia";

// defineStore(唯一ID, 配置对象)
export const useCounterStore = defineStore("counter", {
  // 状态
  state: () => ({
    count: 0,
    name: "计数器",
  }),

  // 计算属性
  getters: {
    doubleCount: (state) => state.count * 2,
    // 带参数的 getter
    multiply: (state) => (n: number) => state.count * n,
  },

  // 方法（同步/异步都可以）
  actions: {
    increment() {
      this.count++;
    },
    decrement() {
      this.count--;
    },
    reset() {
      this.count = 0;
    },
  },
});
```

##### 组合式

```ts
// src/stores/counter.ts  Composition API 风格
import { defineStore } from "pinia";
import { ref, computed } from "vue";

export const useCounterStore = defineStore("counter", () => {
  // state → ref
  const count = ref(0);
  const name = ref("计数器");

  // getters → computed
  const doubleCount = computed(() => count.value * 2);

  // actions → 普通函数
  function increment() {
    count.value++;
  }
  function decrement() {
    count.value--;
  }
  function reset() {
    count.value = 0;
  }

  // 必须 return 出去
  return { count, name, doubleCount, increment, decrement, reset };
});
```

##### 优缺点

###### 选项式

```ts
// Options Store
defineStore("user", {
  state: () => ({}),
  getters: {},
  actions: {},
});
```

**优点**：结构清晰，和 Vue2 选项式一致，新手友好
**缺点**：组合式 API 项目中风格不统一，类型推导稍弱

###### 组合式

```ts
// Setup Store
defineStore("user", () => {
  const count = ref(0);
  const double = computed(() => count.value * 2);
  function inc() { count.value++; }
  return { count, double, inc };
});
```

**优点**：

- 与 `<script setup>` 思维完全一致
- 更灵活，可以使用 watch、watchEffect 等
- 类型推导更自然
- 可以引用外部函数、组合式函数

**缺点**：

- `$reset` 需要手动实现
- 需要注意 return 的内容

**推荐**：Vue3 + `<script setup>` 项目用**组合式写法**。

#### 状态数据

State 是 Store 的数据层，存储需要全局共享的响应式数据。

##### 基本定义

```ts

  state: () => ({
    token: "",
    userInfo: {
      id: 0,
      name: "",
      phone: "",
    },
    loginTime: null as Date | null,

```

##### 读取修改

```ts
const userStore = useUserStore();

// 读取
console.log(userStore.token);
console.log(userStore.userInfo.name);

// 直接修改（Pinia 允许直接改 state，不需要 mutations）
userStore.token = "abc123";
userStore.userInfo.name = "张三";
```

##### 批量修改

```ts
// 方式一：传对象
userStore.$patch({
  token: "new_token",
  userInfo: { ...userStore.userInfo, name: "李四" },
});

// 方式二：传函数（推荐，适合复杂修改）

  state.token = "new_token";
  state.userInfo.name = "李四";
  state.loginTime = new Date();
});
```

> `$patch` 的优势：多次修改合并为一次，触发一次更新，DevTools 中只记录一条。

##### 重置状态

##### 替换状态


#### 计算属性

Getters 相当于 Store 的计算属性，有缓存，依赖变化才重新计算。

##### 基础用法

```ts
export const useProductStore = defineStore("product", {
  state: () => ({
    items: [
      { id: 1, name: "苹果", price: 5, quantity: 2 },
      { id: 2, name: "香蕉", price: 3, quantity: 5 },
    ],
    discount: 0.8, // 8折
  }),

  getters: {
    // 自动推导返回类型
    totalPrice(state) {
      return state.items.reduce((sum, item) => sum + item.price * item.quantity, 0);
    },

    // 显式标注类型（当用到 this 时必须标注）
    finalPrice(): number {
      return this.totalPrice * this.discount;
    },

    // 带参数的 getter（返回一个函数）
    getItemById: (state) => (id: number) => {
      return state.items.find((item) => item.id === id);
    },
  },
});
```

> ```ts
> const productStore = useProductStore();
> console.log(productStore.totalPrice);  // 25
> console.log(productStore.finalPrice);  // 20
> console.log(productStore.getItemById(1)); // { id:1, name:"苹果", ... }
> ```

##### 相互调用

```ts
getters: {
  // 用 this 访问其他 getter
  finalPrice(): number {
    return this.totalPrice * this.discount;
  },
},
```

> 注意：使用 `this` 时必须显式标注返回类型，否则 TS 无法推导。

##### 组合写法

```ts
export const useProductStore = defineStore("product", () => {
  const items = ref([...]);
  const discount = ref(0.8);

  const totalPrice = computed(() =>
    items.value.reduce((sum, item) => sum + item.price * item.quantity, 0)
  );

  const finalPrice = computed(() => totalPrice.value * discount.value);

  const getItemById = (id: number) => items.value.find((item) => item.id === id);

  return { items, discount, totalPrice, finalPrice, getItemById };
});
```

#### 方法执行

Actions 是 Store 的方法层，可以是同步也可以是异步，是唯一应该包含业务逻辑的地方。

##### 同步方法

```ts
export const useCartStore = defineStore("cart", {
  state: () => ({
    items: [] as { id: number; name: string; price: number; qty: number }[],
  }),

  actions: {
    addItem(product: { id: number; name: string; price: number }) {
      const existing = this.items.find((i) => i.id === product.id);
      if (existing) {
        existing.qty++;
      } else {
        this.items.push({ ...product, qty: 1 });
      }
    },

    removeItem(id: number) {
      const index = this.items.findIndex((i) => i.id === id);
      if (index > -1) this.items.splice(index, 1);
    },

    clearCart() {
      this.items = [];
    },
  },
});
```

##### 异步方法

```ts
import { reqLogin } from "@/api/user";

export const useUserStore = defineStore("user", {
  state: () => ({
    token: localStorage.getItem("token") || "",
    userInfo: null as null | { id: number; name: string; phone: string },
    loading: false,
  }),

  actions: {
    async login(phone: string, code: string) {
      this.loading = true;
      try {
        const res = await reqLogin(phone, code);
        this.token = res.data.token;
        this.userInfo = { id: 1, name: res.data.name, phone };
        localStorage.setItem("token", res.data.token);
        return res; // 可以返回值给调用方
      } catch (error) {
        console.error("登录失败", error);
        throw error; // 抛出错误让组件处理
      } finally {
        this.loading = false;
      }
    },

    logout() {
      this.token = "";
      this.userInfo = null;
      localStorage.removeItem("token");
    },
  },
});
```

#### 解构响应

如下示范Store的解构与响应式的错误示范和正确示范：

##### 错误示范

```ts
const store = useCounterStore();
const { count, doubleCount } = store; // ❌ 解构后失去响应式
```

##### 正确示范

```ts
import { storeToRefs } from "pinia";
const store = useCounterStore();
// state 和 getters → storeToRefs
const { count, doubleCount } = storeToRefs(store);
// actions → 直接解构
const { increment, reset } = store;
```

##### 基本原理

`storeToRefs` 会为每个 state 和 getter 创建 `toRef`，保持与 store 的响应式连接。actions 是函数，不需要响应式，直接解构即可。

### 进阶用法

#### 异步方法

##### 异步流程

```ts
// src/stores/hospital.ts
import { defineStore } from "pinia";
import { ref } from "vue";
import { reqHospitalPage, reqHospitalDetail } from "@/api/hospital";

export const useHospitalStore = defineStore("hospital", () => {
  // 状态
  const hospitalList = ref<any[]>([]);
  const total = ref(0);
  const loading = ref(false);
  const error = ref<string | null>(null);
  const currentHospital = ref<any>(null);

  // 异步 Action：获取医院列表
  async function fetchHospitalList(page: number, limit: number, params = {}) {
    loading.value = true;
    error.value = null;
    try {
      const res = await reqHospitalPage(page, limit, params);
      hospitalList.value = res.data.content;
      total.value = res.data.totalElements;
      return res.data;
    } catch (e: any) {
      error.value = e.message || "获取医院列表失败";
      throw e;
    } finally {
      loading.value = false;
    }
  }

  // 异步 Action：获取医院详情
  async function fetchHospitalDetail(hoscode: string) {
    loading.value = true;
    try {
      const res = await reqHospitalDetail(hoscode);
      currentHospital.value = res.data;
      return res.data;
    } finally {
      loading.value = false;
    }
  }

  return {
    hospitalList, total, loading, error, currentHospital,
    fetchHospitalList, fetchHospitalDetail,
  };
});
```

##### 竞态处理

```ts
import { defineStore } from "pinia";
import { ref } from "vue";

export const useSearchStore = defineStore("search", () => {
  const results = ref([]);
  const loading = ref(false);
  let abortController: AbortController | null = null;

  async function search(keyword: string) {
    // 取消上一次请求
    abortController?.abort();
    abortController = new AbortController();

    loading.value = true;
    try {
      const res = await fetch(`/api/search?q=${keyword}`, {
        signal: abortController.signal,
      });
      results.value = await res.json();
    } catch (e) {
      if (e.name !== "AbortError") throw e;
    } finally {
      loading.value = false;
    }
  }

  return { results, loading, search };
});
```

#### 相互调用

##### 基本使用

Store 之间可以自由互相调用，直接 import 对应的 `useXxxStore` 即可。

```ts
// src/stores/order.ts
import { defineStore } from "pinia";
import { ref } from "vue";
import { useUserStore } from "./user";
import { useHospitalStore } from "./hospital";

export const useOrderStore = defineStore("order", () => {
  const orders = ref<any[]>([]);

  async function createOrder(scheduleId: number, patientId: number) {
    // 调用其他 store
    const userStore = useUserStore();
    const hospitalStore = useHospitalStore();

    if (!userStore.token) {
      throw new Error("请先登录");
    }

    // 从 hospitalStore 获取当前医院信息
    const hospital = hospitalStore.currentHospital;

    // ... 创建订单逻辑
    const order = {
      id: Date.now(),
      userId: userStore.userInfo?.id,
      hospitalName: hospital?.hosname,
      scheduleId,
      patientId,
      status: "pending",
    };
    orders.value.unshift(order);
    return order;
  }

  return { orders, createOrder };
});
```

> **注意**：在 Store 顶层（setup 函数顶部）直接调用其他 `useXxxStore()` 可能导致循环依赖。建议在 **action 函数内部**调用。

##### 避免依赖

```ts
// ❌ 可能导致循环依赖
export const useAStore = defineStore("a", () => {
  const bStore = useBStore(); // 顶部调用，如果 B 也调用 A 就死循环
  // ...
});

// ✅ 在 action 中调用
export const useAStore = defineStore("a", () => {
  function doSomething() {
    const bStore = useBStore(); // 安全
    bStore.someAction();
  }
  return { doSomething };
});
```

#### 状态变化

##### 基本介绍

订阅状态变化，即监听 state 的变化，类似 Vue 的 `watch`，但作用于整个 Store。

```ts
const userStore = useUserStore();

// 订阅状态变化
const unsubscribe = userStore.$subscribe((mutation, state) => {
  console.log("变化类型:", mutation.type); // "direct" | "patch object" | "patch function"
  console.log("变化的 storeId:", mutation.storeId); // "user"
  console.log("变化的 payload:", mutation.payload); // 具体变化内容
  console.log("新状态:", state);

  // 持久化到 localStorage
  localStorage.setItem("user", JSON.stringify(state));
}, {
  detached: true, // 组件卸载后不自动停止订阅
  deep: true,     // 深度监听（默认 true）
});

// 停止订阅
unsubscribe();
```

##### 类型说明

mutation.type 说明如下：

| type               | 触发方式                           |
| ------------------ | ---------------------------------- |
| `"direct"`         | 直接修改 state，如 `store.count++` |
| `"patch object"`   | `store.$patch({...})`              |
| `"patch function"` | `store.$patch(state => {...})`     |

##### 实际应用

其实质是自动持久：


#### 订阅方法

##### 基本介绍

监听 actions 的调用，可以做日志、错误捕获、性能监控。

```ts
const userStore = useUserStore();

userStore.$onAction(({
  name,           // action 名称
  store,          // store 实例
  args,           // 调用参数
  after,          // action 成功后的回调
  onError,        // action 出错后的回调
}) => {
  const startTime = Date.now();
  console.log(`[Action] ${name} 开始，参数:`, args);

  after((result) => {
    console.log(`[Action] ${name} 完成，耗时: ${Date.now() - startTime}ms，结果:`, result);
  });

  onError((error) => {
    console.error(`[Action] ${name} 失败:`, error);
  });
}, true); // 第二个参数 true = detached，组件卸载后不停止
```

##### 实际应用

用于全局错误处理：

```ts
// 在 main.ts 中为所有 store 注册 action 监听
import { createPinia } from "pinia";

const pinia = createPinia();

pinia.use(({ store }) => {

      // 可以统一上报错误
      // reportError(error, { store: store.$id, action: name, args });
    });
  });
});
```

#### 组合状态

##### 基本使用

组合式 Store 写法参考如下：

```ts
// src/stores/user.ts 完整示例
import { defineStore } from "pinia";
import { ref, computed } from "vue";
import { reqLogin, reqUserInfo } from "@/api/user";

export const useUserStore = defineStore("user", () => {
  // ===== State =====
  const token = ref<string>(localStorage.getItem("token") || "");
  const userInfo = ref<UserInfo | null>(null);
  const loading = ref(false);

  // ===== Getters =====
  const isLoggedIn = computed(() => !!token.value);
  const userName = computed(() => userInfo.value?.name || "未登录");

  // ===== Actions =====
  async function login(phone: string, code: string) {
    loading.value = true;
    try {
      const res = await reqLogin(phone, code);
      token.value = res.data.token;
      userInfo.value = res.data;
      localStorage.setItem("token", res.data.token);
      return res.data;
    } finally {
      loading.value = false;
    }
  }

  async function fetchUserInfo() {
    if (!token.value) return null;
    const res = await reqUserInfo();
    userInfo.value = res.data;
    return res.data;
  }

  function logout() {
    token.value = "";
    userInfo.value = null;
    localStorage.removeItem("token");
  }

  function $reset() {
    token.value = "";
    userInfo.value = null;
    loading.value = false;
  }

  return {
    // state
    token, userInfo, loading,
    // getters
    isLoggedIn, userName,
    // actions
    login, fetchUserInfo, logout, $reset,
  };
});

// 类型定义
interface UserInfo {
  id: number;
  name: string;
  phone: string;
}
```

#### 自定义插件

Pinia 插件是一个函数，可以扩展所有 Store 的功能。

##### 插件结构

```ts
// src/stores/plugins/logger.ts
import type { PiniaPluginContext } from "pinia";

export function piniaLoggerPlugin(context: PiniaPluginContext) {
  const { store, options, pinia, app } = context;

  // 为每个 store 添加属性/方法
  store.$log = (action: string, ...args: any[]) => {
    console.log(`[${store.$id}] ${action}:`, ...args);
  };

  // 订阅所有 state 变化
  store.$subscribe((mutation, state) => {
    console.log(`[State Change] ${store.$id}`, mutation.type, mutation.payload);
  });

  // 订阅所有 action
  store.$onAction(({ name, args, after, onError }) => {
    console.log(`[Action] ${store.$id}.${name}`, args);
    after((result) => console.log(`[Action Done] ${name}`, result));
    onError((err) => console.error(`[Action Error] ${name}`, err));
  });

  // 返回的对象会合并到 store 上
  return {
    createdAt: new Date().toISOString(),
  };
}
```

```ts
// src/stores/plugins/loading.ts
import type { PiniaPluginContext } from "pinia";

export function piniaLoadingPlugin({ store }: PiniaPluginContext) {
  let pendingCount = 0;

  store.$onAction(({ name, after, onError }) => {
    // 只处理 async action（通过判断返回值）
    pendingCount++;
    store.$patch({ globalLoading: true });

    const finish = () => {
      pendingCount--;
      if (pendingCount === 0) {
        store.$patch({ globalLoading: false });
      }
    };

    after(finish);
    onError(finish);
  });
}
```

##### 设计原则

1. **单一职责**：一个 Store 只管理一个领域的状态
2. **避免过大**：单个 Store 超过 200 行考虑拆分
3. **共享数据放 Store，局部数据放组件**：不是所有数据都要全局
4. **Actions 放业务逻辑**：组件只负责调用和展示
5. **Getters 放派生数据**：不要在组件里重复计算

##### 基本定义

```ts
// src/stores/modules/user.ts
import { defineStore } from "pinia";
import { ref, computed } from "vue";
import { reqLogin, reqUserInfo, reqAuthUser, reqLogout } from "@/api/user";
import { reqPatientList, reqPatientSave, reqPatientUpdate, reqPatientDelete } from "@/api/patient";
import type { UserInfo, Patient } from "../types";

export const useUserStore = defineStore("user", () => {
  // ===== State =====
  const token = ref<string>(localStorage.getItem("syt_token") || "");
  const userInfo = ref<UserInfo | null>(
    JSON.parse(localStorage.getItem("syt_userInfo") || "null")
  );
  const patients = ref<Patient[]>([]);
  const loading = ref(false);

  // ===== Getters =====
  const isLoggedIn = computed(() => !!token.value);
  const isAuthed = computed(() => userInfo.value?.authStatus === 1);
  const defaultPatient = computed<Patient | null>(
    () => patients.value.find((p) => p.isDefault === 1) || patients.value[0] || null
  );

  // ===== Actions =====
  async function login(phone: string, code: string) {
    loading.value = true;
    try {
      const res = await reqLogin(phone, code);
      token.value = res.data.token;
      userInfo.value = res.data;
      localStorage.setItem("syt_token", res.data.token);
      localStorage.setItem("syt_userInfo", JSON.stringify(res.data));
      return res.data;
    } finally {
      loading.value = false;
    }
  }

  async function fetchUserInfo() {
    if (!token.value) return null;
    const res = await reqUserInfo();
    userInfo.value = res.data;
    localStorage.setItem("syt_userInfo", JSON.stringify(res.data));
    return res.data;
  }

  async function authUser(data: { name: string; certificatesType: string; certificatesNo: string }) {
    const res = await reqAuthUser(data);
    if (userInfo.value) {
      userInfo.value.authStatus = 1;
      userInfo.value.name = data.name;
    }
    return res;
  }

  async function logout() {
    try {
      await reqLogout();
    } finally {
      token.value = "";
      userInfo.value = null;
      patients.value = [];
      localStorage.removeItem("syt_token");
      localStorage.removeItem("syt_userInfo");
    }
  }

  // 就诊人管理
  async function fetchPatients() {
    if (!token.value) return;
    const res = await reqPatientList();
    patients.value = res.data;
    return res.data;
  }

  async function savePatient(data: Omit<Patient, "id">) {
    const res = await reqPatientSave(data);
    await fetchPatients(); // 刷新列表
    return res;
  }

  async function updatePatient(data: Patient) {
    const res = await reqPatientUpdate(data);
    await fetchPatients();
    return res;
  }

  async function deletePatient(id: number) {
    await reqPatientDelete(id);
    patients.value = patients.value.filter((p) => p.id !== id);
  }

  function $reset() {
    token.value = "";
    userInfo.value = null;
    patients.value = [];
    loading.value = false;
  }

  return {
    token, userInfo, patients, loading,
    isLoggedIn, isAuthed, defaultPatient,
    login, fetchUserInfo, authUser, logout,
    fetchPatients, savePatient, updatePatient, deletePatient,
    $reset,
  };
});
```

#### 搜索模块

##### 基本定义

```ts
// src/stores/modules/hospital.ts
import { defineStore } from "pinia";
import { ref, computed } from "vue";
import { reqHospitalPage, reqHospitalDetail, reqDepartment, reqFindByHosname } from "@/api/hospital";

export const useHospitalStore = defineStore("hospital", () => {
  // ===== State =====
  const hospitalList = ref<any[]>([]);
  const total = ref(0);
  const totalPages = ref(0);
  const currentPage = ref(1);
  const pageSize = ref(10);
  const loading = ref(false);

  // 筛选条件
  const filters = ref({
    hosname: "",
    hostype: "",
    provinceCode: "",
    cityCode: "",
    districtCode: "",
  });

  // 搜索建议
  const searchSuggestions = ref<{ id: string; hosname: string; hoscode: string }[]>([]);

  // 当前选中的医院详情
  const currentHospital = ref<any>(null);
  const departments = ref<any[]>([]);

  // ===== Getters =====
  const hasMore = computed(() => currentPage.value < totalPages.value);

  // ===== Actions =====
  async function fetchHospitalList(page = 1, limit = 10) {
    loading.value = true;
    try {
      const res = await reqHospitalPage(page, limit, filters.value);
      hospitalList.value = res.data.content;
      total.value = res.data.totalElements;
      totalPages.value = res.data.totalPages;
      currentPage.value = page;
      pageSize.value = limit;
      return res.data;
    } finally {
      loading.value = false;
    }
  }

  async function fetchHospitalDetail(hoscode: string) {
    const res = await reqHospitalDetail(hoscode);
    currentHospital.value = res.data;
    return res.data;
  }

  async function fetchDepartments(hoscode: string) {
    const res = await reqDepartment(hoscode);
    departments.value = res.data;
    return res.data;
  }

  async function searchHosname(keyword: string) {
    if (!keyword.trim()) {
      searchSuggestions.value = [];
      return;
    }
    const res = await reqFindByHosname(keyword);
    searchSuggestions.value = res.data;
    return res.data;
  }

  function setFilters(newFilters: Partial<typeof filters.value>) {
    Object.assign(filters.value, newFilters);
    currentPage.value = 1; // 筛选条件变化时重置页码
  }

  function clearFilters() {
    filters.value = { hosname: "", hostype: "", provinceCode: "", cityCode: "", districtCode: "" };
    currentPage.value = 1;
  }

  return {
    hospitalList, total, totalPages, currentPage, pageSize, loading,
    filters, searchSuggestions, currentHospital, departments,
    hasMore,
    fetchHospitalList, fetchHospitalDetail, fetchDepartments,
    searchHosname, setFilters, clearFilters,
  };
});
```

```ts
  function showLoading() {
    loadingCount++;
    globalLoading.value = true;
  }

  function hideLoading() {
    loadingCount = Math.max(0, loadingCount - 1);
    if (loadingCount === 0) {
      globalLoading.value = false;
    }
  }

  // 侧边栏
  const sidebarCollapsed = ref(false);
  function toggleSidebar() {
    sidebarCollapsed.value = !sidebarCollapsed.value;
  }

  // 主题
  const theme = ref<"light" | "dark">(
    (localStorage.getItem("syt_theme") as "light" | "dark") || "light"
  );
  function toggleTheme() {
    theme.value = theme.value === "light" ? "dark" : "light";
    localStorage.setItem("syt_theme", theme.value);
  }

  return {
    globalLoading, showLoading, hideLoading,
    sidebarCollapsed, toggleSidebar,
    theme, toggleTheme,
  };
});
```

```ts
// src/utils/request.ts
import axios from "axios";
import { useAppStore } from "@/stores/modules/app";

const request = axios.create({ baseURL: "/api" });

request.interceptors.request.use((config) => {
  const appStore = useAppStore();
  appStore.showLoading();
  return config;
});

request.interceptors.response.use(
  (response) => {
    const appStore = useAppStore();
    appStore.hideLoading();
    return response;
  },
  (error) => {
    const appStore = useAppStore();
    appStore.hideLoading();
    return Promise.reject(error);
  }
);
```
