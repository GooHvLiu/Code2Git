# 03.05 前端支持

## mockjs

### 基础知识

#### 基本定义

Mock.js 拦截浏览器 XMLHttpRequest 请求，前端直接模拟后端接口返回假数据，不需要启动后端服务，前端可以独立开发页面，后端接口完成后直接关掉 mock 即可，业务代码完全不用修改。

#### 核心能力

1. 生成随机模拟数据（姓名、手机号、时间、数组、自增 ID）
2. 拦截 AJAX/axios 请求，匹配 url + 请求方法，返回自定义 JSON

> 注意：Mock.js只在浏览器端生效，node 环境不能拦截 http 请求，打包生产环境必须关闭 mock，不能带到线上。

#### 关键概念

1. mockjs 只匹配 url 路径部分，不关心域名、端口。
2. axios `baseURL: '/prod-api/v2'`，这是前端代理前缀；mock 的正则只写后面路径。
3. 开发环境 vite/webpack devServer 的端口（比如 `localhost:9528`）是 vue 前端服务端口，mock 完全不碰这个端口。
4. 当 mock 匹配成功：直接本地返回模拟数据；匹配失败：才会真的发 http 请求走代理到后端。

#### 安装依赖

```bash
# 开发依赖，只本地用，不要打包进生产
npm install mockjs --save-dev
```

### 核心 API

#### 基本使用

`Mock.mock(rurl, rtype, template|callback)` 

- `rurl`：拦截的接口地址，可以字符串 / 正则
- `rtype`：请求方法，小写 `get/post/put/delete`，必须写，否则拦截全部 method
- `template`：返回的数据模板
- `callback(options)`：回调函数，可以拿到请求参数，模拟后端业务逻辑，`options.body`拿到 post 传参

```js
import Mock from 'mockjs'
// 写法1：直接模板
Mock.mock('/api/user/list','get',{
  code:200,
  msg:'成功',
  'data|10':[{
    'id|+1':1, // id自增
    name:'@cname'
  }]
})

// 写法2：回调函数，可以读取前端传过来参数，做判断（模拟登录校验）
Mock.mock('/api/login','post',(options)=>{
  // post参数在 options.body 是字符串，需要JSON.parse
  const body = JSON.parse(options.body)
  if(body.username === 'admin' && body.password === '123456'){
    return { code:200, data:{token:'admin-token'} }
  }else{
    return { code:400, msg:'账号密码错误' }
  }
})
```

#### 网络延迟

`Mock.setup({timeout:'200‑600'})`,模拟网络延迟，模拟真实接口耗时，单位 ms

```js
Mock.setup({
  timeout:'200‑800' // 请求延迟200~800毫秒随机
})
```

#### 生成数据

`Mock.mock(template)` 只生成随机数据对象，用于 js 代码内直接使用，不拦截网络：

```js
const data = Mock.mock({
  'list|5':[{ id:'@increment', name:'@cname' }]
})
console.log(data)
```

### 数据模板

#### 基本格式

格式：`'属性名|生成规则':初始值`

#### 数组规则

```js
Mock.mock({
  'arr1|5': [1],       // 数组重复5次 [1,1,1,1,1]
  'arr2|3‑8': [{}],    // 数组长度3‑8随机
  'id|+1': 1           // id自增，初始1，每次+1（表格列表必用）
})
```

#### 数字规则

```js
Mock.mock({
  'age|18‑60': 1,          // 18‑60随机整数
  'price|100‑500.1‑2':100  // 整数100‑500，小数1‑2位
})
```

#### 随机占位

随机占位符 `@xxx`（Mock 内置）:

| 占位符              | 作用                           |
| ------------------- | ------------------------------ |
| `@cname`            | 中文姓名                       |
| `@integer(min,max)` | 整数                           |
| `@datetime`         | 日期时间 `2020‑02‑02 12:10:30` |
| `@date`             | 日期 `2025‑08‑08`              |
| `@phone`            | 手机号                         |
| `@email`            | 邮箱                           |
| `@county(true)`     | 省 市 地址                     |
| `@increment`        | 自增数字                       |
| `@guid`             | uuid token 字符串              |
| `@cparagraph(2,4)`  | 中文段落                       |

```js
Mock.mock({
  code:200,
  data:{
    id:'@increment',
    username:'@cname',
    mobile:/^1[3‑9]\d{9}$/, //正则生成手机号
    createTime:'@datetime',
    address:'@county(true)'
  }
})
```

> 也可以调用函数 `Mock.Random.cname()`，等价于`@cname`

### 标准目录

vue‑element‑admin 标准项目目录（大厂规范）：

```text
src
├─mock
│   ├─index.js      # mock入口，自动导入所有模块，setup全局配置
│   ├─user.js       # 用户登录接口mock
│   └─customer.js   # 客户管理接口mock
├─api
│   └─customer.js   # axios请求，业务代码完全不变
└─main.js
```

#### 导入主页

```js
// src/mock/index.js
import Mock from 'mockjs'

// 模拟网络延时
Mock.setup({
  timeout:'200‑600'
})

// require.context 批量导入mock文件夹下所有js，不用手动一个个import
const modulesFiles = require.context('./', true, /\.js$/)
modulesFiles.keys().forEach(key=>{
  if(key !== './index.js'){
    modulesFiles(key)
  }
})
```

#### 模拟接口

```js
// src/mock/customer.js（写模拟接口）
import Mock from 'mockjs'

// 获取客户列表 GET /api/customer
Mock.mock(/\/api\/customer/, 'get', (options)=>{
  // 可以解析url上query参数，做分页逻辑
  return Mock.mock({
    code:200,
    message:'success',
    data:{
      total:136,
      'records|10':[{
        id:'@increment',
        name:'@cname',
        phone:/^1[3‑9]\d{9}$/,
        'sex|1':[0,1],
        agent:'@cname',
        createTime:'@datetime'
      }]
    }
  })
})

// 更新客户 put /api/customer/1
Mock.mock(/\/api\/customer\/\d+/, 'put', ()=>{
  return { code:200, message:'更新成功' }
})
```

#### 控制启用

main.js 控制是否启用 mock，生产环境绝对不要加载 mock！ 使用环境变量控制开关，和 vue‑element‑admin 一模一样：

```js
// .env.development 配置 VUE_APP_MOCK=true
if(process.env.VUE_APP_MOCK === 'true'){
  require('@/mock')
}
```

##### 开发环境

```env
// .env.development
VUE_APP_BASE_API = '/api'
VUE_APP_MOCK = true
```

##### 生产环境

```env
.env.production
VUE_APP_MOCK = false
```

### 模拟分页

mock 读取 url query 参数，模拟分页返回对应条数:

```js
Mock.mock(/\/api\/customer/, 'get', (options)=>{
  // 解析url获取page、pageSize
  const url = new URL(options.url,'http://dummy')
  const page = Number(url.searchParams.get('page')) ||1
  const pageSize = Number(url.searchParams.get('pageSize'))||10

  return Mock.mock({
    code:200,
    data:{
      total:123,
      [`records|${pageSize}`]:[{
        id:'@increment',
        name:'@cname'
      }]
    }
  })
})
```

### 注意事项

* 请求方法必须写 `get/post`，小写，不写会拦截全部请求，造成 bug；

* post 请求参数在 `options.body`，是 JSON 字符串，要`JSON.parse(options.body)`；

* 打包生产环境关闭 mock，`VUE_APP_MOCK=false`，mockjs 不能上生产；

* Mock 只能拦截浏览器 axios，不能拦截后端 node 的 axios 请求；

* chrome Network 面板看不到 mock 请求真实 http，请求被 js 拦截，不会真正发出网络包，在 console 打印调试；

* url 匹配优先用正则`/\/api\/customer/`，处理带参数 url，不要写死字符串；

#### 创建文件

##### 创建目录

在`src/mock`创建后，创建如下几个项目：

###### index.js

```js
import Mock from 'mockjs'
import { ERROR_CODE } from '../base/constants'

// 模拟用户数据库
const mockUserDB = [
  { id:1, username:'admin', password:'123456', nickname:'超级管理员', roles:['admin'] }
]

// 简易内存存储token
let tokenStore = {}

// ------------------- Mock拦截所有请求 -------------------
Mock.setup({
  timeout: 300‑800 // 模拟网络延迟，感受loading
})

// 工具函数：简易校验token，从header取 Authorization: Bearer xxx
function verifyToken(config){
  const auth = config.headers.Authorization
  if(!auth || !auth.startsWith('Bearer ')){
    return { ok:false, code:ERROR_CODE.UNAUTHORIZED, msg:'未登录，请先登录' }
  }
  const token = auth.replace('Bearer ','')
  if(!tokenStore[token]){
    return { ok:false, code:ERROR_CODE.TOKEN_EXPIRED, msg:'登录已过期，请重新登录' }
  }
  return { ok:true, user: tokenStore[token] }
}

// 1、登录接口 post /prod-api/v2/user/login
Mock.mock(/\/prod-api\/v2\/user\/login/, 'post', (options)=>{
  const body = JSON.parse(options.body)
  const {username,password} = body
  const user = mockUserDB.find(u=>u.username === username)
  if(!user){
    return { code:ERROR_CODE.USER_NOT_EXIST, msg:'用户不存在', data:null }
  }
  if(user.password !== password){
    return { code:ERROR_CODE.USER_PASSWORD_ERROR, msg:'密码错误', data:null }
  }
  // 生成模拟token
  const mockToken = 'mock_token_' + Mock.Random.guid()
  tokenStore[mockToken] = user
  return {
    code: ERROR_CODE.SUCCESS,
    msg:'操作成功',
    data:{ token:mockToken }
  }
})

// 2、获取用户信息 get /prod-api/v2/user/info
Mock.mock(/\/prod-api\/v2\/user\/info/, 'get', (options)=>{
  const tokenCheck = verifyToken(options)
  if(!tokenCheck.ok){
    return { code:tokenCheck.code, msg:tokenCheck.msg, data:null }
  }
  const u = tokenCheck.user
  return {
    code:ERROR_CODE.SUCCESS,
    msg:'操作成功',
    data:{ id:u.id, username:u.username, nickname:u.nickname, roles:u.roles }
  }
})

//3、验证码接口 get /prod-api/v2/captcha/captchaImage
Mock.mock(/\/prod-api\/v2\/captcha\/captchaImage/,'get',()=>{
  return {
    code:ERROR_CODE.SUCCESS,
    msg:'操作成功',
    data:{ captchaId:Mock.Random.guid(), image:'data:image/svg+xml;base64,xxxx' }
  }
})

//4、菜单接口 get /prod-api/v2/menu/getRouters
Mock.mock(/\/prod-api\/v2\/menu\/getRouters/,'get',(options)=>{
  const tokenCheck = verifyToken(options)
  if(!tokenCheck.ok){
    return { code:tokenCheck.code, msg:tokenCheck.msg, data:null }
  }
  return {
    code:ERROR_CODE.SUCCESS,
    msg:'操作成功',
    data:[
      { path:'/dashboard', name:'Dashboard', meta:{title:'仪表盘'} },
      { path:'/customer', name:'Customer', meta:{title:'客户管理'} }
    ]
  }
})

export default Mock
```
