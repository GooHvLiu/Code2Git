## useCrud <a name="usecrud"></a>

### 概述

`useCrud` 是一个封装了列表页通用 CRUD 逻辑的组合式函数，包含：
- 列表数据获取、搜索、分页
- 新增/编辑弹窗的显示隐藏、表单重置、提交
- 删除确认、删除后刷新
- 加载状态管理

### 适用场景

- 标准的单列表 CRUD 页面
- 无特殊业务逻辑的管理页面
- 快速原型开发

### 不适用场景

- 有多个独立列表的页面（如字典管理）
- 有复杂业务逻辑的页面（如角色权限分配）
- 树形结构页面（如部门管理）
- 有特殊交互的页面（如设备管理的踢设备功能）

### 基本使用

```javascript
import { useCrud } from '@/composables/useCrud'
import {
  getUserListApi,
  createUserApi,
  updateUserApi,
  deleteUserApi
} from '@/api/user'

export default {
  setup() {
    const {
      // 列表相关
      loading,
      tableData,
      total,
      pageNum,
      pageSize,
      queryParams,
      getList,
      handleQuery,
      handleReset,
      handlePageChange,
      handleSizeChange,
      // 弹窗相关
      dialogVisible,
      submitLoading,
      dialogTitle,
      isEdit,
      currentId,
      openDialog,
      closeDialog,
      handleSubmit,
      // 删除相关
      deleteLoading,
      handleDelete,
      // 表单相关
      form,
      formRef,
      resetForm,
      validateForm
    } = useCrud({
      // API 相关
      listApi: getUserListApi,
      createApi: createUserApi,
      updateApi: updateUserApi,
      deleteApi: deleteUserApi,
      // 表单相关
      defaultForm: {
        username: '',
        password: '',
        email: '',
        status: 1
      },
      // 标题相关
      addTitle: '新增用户',
      editTitle: '编辑用户',
      deleteTitle: '删除确认',
      deleteMessage: '确定要删除该用户吗？',
      // 其他
      immediate: true, // 是否立即获取列表
      beforeFetch: (params) => params, // 获取列表前的钩子
      afterFetch: (res) => {}, // 获取列表后的钩子
      beforeSubmit: (form, isEdit) => form, // 提交前的钩子
      afterSubmit: (form, isEdit) => {}, // 提交后的钩子
      beforeDelete: (row) => row.id, // 删除前的钩子
      afterDelete: (row) => {} // 删除后的钩子
    })

    return {
      loading,
      tableData,
      total,
      pageNum,
      pageSize,
      queryParams,
      getList,
      handleQuery,
      handleReset,
      handlePageChange,
      handleSizeChange,
      dialogVisible,
      submitLoading,
      dialogTitle,
      openDialog,
      closeDialog,
      handleSubmit,
      deleteLoading,
      handleDelete,
      form,
      formRef
    }
  }
}
```

## ConfirmDialog <a name="confirmdialog"></a>

### 概述

`ConfirmDialog` 是一个统一的确认弹窗组件，支持多种类型（warning/error/info/success），统一的图标和样式。

### 基本使用

```vue
<template>
  <div>
    <el-button @click="handleDelete">删除</el-button>
    <ConfirmDialog
      ref="confirmDialogRef"
      title="删除确认"
      message="确定要删除这条记录吗？删除后不可恢复。"
      type="warning"
      confirm-text="确定删除"
      cancel-text="取消"
      confirm-type="danger"
      @confirm="handleConfirmDelete"
      @cancel="handleCancel"
    />
  </div>
</template>

<script>
import ConfirmDialog from '@/components/ConfirmDialog/index.vue'

export default {
  components: { ConfirmDialog },
  data() {
    return {
      confirmDialogRef: null,
      currentRow: null
    }
  },
  methods: {
    handleDelete(row) {
      this.currentRow = row
      this.$refs.confirmDialogRef.open()
    },
    async handleConfirmDelete() {
      // 执行删除操作
      await deleteApi(this.currentRow.id)
      this.$refs.confirmDialogRef.close()
      this.getList()
    },
    handleCancel() {
      console.log('用户取消')
    }
  }
}
</script>
```

### Props

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| title | String | '确认' | 弹窗标题 |
| message | String | - | 提示内容（必填） |
| width | String | '420px' | 弹窗宽度 |
| type | String | 'warning' | 类型：warning/error/info/success |
| confirmText | String | '确定' | 确认按钮文字 |
| cancelText | String | '取消' | 取消按钮文字 |
| confirmType | String | 'primary' | 确认按钮类型 |
| showTitle | Boolean | false | 是否显示标题文字 |
| titleText | String | '' | 标题文字 |
| loading | Boolean | false | 确认按钮加载状态 |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| confirm | 点击确认按钮 | - |
| cancel | 点击取消按钮 | - |
| close | 弹窗关闭 | - |

### Methods

| 方法名 | 说明 |
|--------|------|
| open() | 打开弹窗 |
| close() | 关闭弹窗 |

## FormDialog <a name="formdialog"></a>

### 概述

`FormDialog` 是一个统一的表单弹窗组件，自动切换新增/编辑标题，内置表单校验，支持自定义表单内容。

### 基本使用

```vue
<template>
  <div>
    <el-button @click="handleAdd">新增</el-button>
    <el-button @click="handleEdit(row)">编辑</el-button>

    <FormDialog
      ref="formDialogRef"
      add-title="新增用户"
      edit-title="编辑用户"
      :form="form"
      :rules="rules"
      width="500px"
      label-width="100px"
      @submit="handleSubmit"
      @cancel="handleCancel"
    >
      <template #form-content="{ form, disabled }">
        <el-form-item label="用户名" prop="username">
          <el-input v-model="form.username" :disabled="disabled" />
        </el-form-item>
        <el-form-item label="邮箱" prop="email">
          <el-input v-model="form.email" :disabled="disabled" />
        </el-form-item>
      </template>
    </FormDialog>
  </div>
</template>

<script>
import FormDialog from '@/components/FormDialog/index.vue'

export default {
  components: { FormDialog },
  data() {
    return {
      form: {
        username: '',
        email: ''
      },
      rules: {
        username: [{ required: true, message: '请输入用户名', trigger: 'blur' }],
        email: [{ required: true, message: '请输入邮箱', trigger: 'blur' }]
      }
    }
  },
  methods: {
    handleAdd() {
      this.form = { username: '', email: '' }
      this.$refs.formDialogRef.open()
    },
    handleEdit(row) {
      this.form = { ...row }
      this.$refs.formDialogRef.open(row)
    },
    async handleSubmit(form, isEdit) {
      if (isEdit) {
        await updateApi(form.id, form)
      } else {
        await createApi(form)
      }
      this.$refs.formDialogRef.close()
      this.getList()
    },
    handleCancel() {
      console.log('用户取消')
    }
  }
}
</script>
```

### Props

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| addTitle | String | '新增' | 新增弹窗标题 |
| editTitle | String | '编辑' | 编辑弹窗标题 |
| width | String | '600px' | 弹窗宽度 |
| form | Object | - | 表单数据（必填） |
| rules | Object | {} | 表单校验规则 |
| labelWidth | String | '100px' | 标签宽度 |
| disabled | Boolean | false | 是否禁用表单 |
| confirmText | String | '确定' | 确认按钮文字 |
| cancelText | String | '取消' | 取消按钮文字 |
| confirmType | String | 'primary' | 确认按钮类型 |
| loading | Boolean | false | 确认按钮加载状态 |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| submit | 表单校验通过后触发 | (form, isEdit) |
| cancel | 点击取消按钮 | - |
| close | 弹窗关闭 | - |

### Methods

| 方法名 | 说明 |
|--------|------|
| open(row?) | 打开弹窗（传 row 为编辑，不传为新增） |
| close() | 关闭弹窗 |
| validate() | 校验表单，返回 Promise<boolean> |
| clearValidate() | 清除校验 |

### Slots

| 插槽名 | 说明 | 作用域参数 |
|--------|------|------------|
| form-content | 表单内容 | { form, disabled } |

## feedback.js <a name="feedback"></a>

### 概述

`feedback.js` 是统一的用户反馈工具，包含消息提示（带防重复）和确认弹窗，替代原来的 `message.js` 和 `confirm.js`。

### 消息提示

```javascript
import {
  showMessage,
  showSuccess,
  showError,
  showWarning,
  showInfo
} from '@/utils/feedback'

// 基本使用
showSuccess('操作成功')
showError('操作失败')
showWarning('警告信息')
showInfo('提示信息')

// 自定义配置
showMessage({
  message: '自定义消息',
  duration: 5000,
  showClose: true
}, 'success')
```

### 确认弹窗

```javascript
import {
  confirmAction,
  confirmDelete,
  confirmBatch,
  confirmDanger,
  confirmLogout
} from '@/utils/feedback'

// 通用确认
const ok = await confirmAction('确定要执行此操作吗？', '操作确认')
if (ok) {
  // 执行操作
}

// 删除确认
const ok = await confirmDelete('确定要删除这条记录吗？删除后不可恢复。')
if (ok) {
  // 执行删除
}

// 批量操作确认
const ok = await confirmBatch(5, '删除')
if (ok) {
  // 执行批量删除
}

// 危险操作确认（需要输入确认文字）
const ok = await confirmDanger('确定要删除所有数据吗？此操作不可恢复！', 'DELETE')
if (ok) {
  // 执行危险操作
}

// 退出登录确认
const ok = await confirmLogout()
if (ok) {
  // 执行退出登录
}
```

### 全局使用（已在 main.js 中注册）

```javascript
// 在组件中可以直接使用
this.$msg.success('操作成功')
this.$msg.error('操作失败')
this.$msg.warning('警告信息')
this.$msg.info('提示信息')

this.$confirm.action('确定要执行此操作吗？')
this.$confirm.delete('确定要删除吗？')
this.$confirm.batch(5, '删除')
this.$confirm.logout()
```

## 后端 BaseService/BaseController 使用指南 <a name="backend"></a>

### 概述

后端提供了 `BaseService` 和 `BaseController` 基类，封装了通用的 CRUD 操作，新模块可以继承使用。

### BaseService 使用

```javascript
// user.service.js
const BaseService = require('../../services/BaseService')
const UserModel = require('./user.model')

class UserService extends BaseService {
  constructor() {
    super(UserModel, {
      name: '用户', // 模块名称，用于错误提示
      langFields: ['username', 'description'] // 需要多语言处理的字段
    })
  }

  // 重写 buildWhere 方法，自定义查询条件
  buildWhere(params = {}) {
    const where = {}
    if (params.username) {
      where.username = params.username
    }
    if (params.status !== undefined && params.status !== '') {
      where.status = params.status
    }
    return where
  }

  // 自定义业务方法
  async resetPassword(userId, newPassword) {
    // 自定义逻辑
  }
}

module.exports = new UserService()
```

### BaseController 使用

```javascript
// user.controller.js
const BaseController = require('../../controllers/BaseController')
const userService = require('./user.service')

class UserController extends BaseController {
  constructor() {
    super(userService)
  }

  // 自定义接口
  async resetPassword(req, res) {
    const { userId, newPassword } = req.body
    await this.service.resetPassword(userId, newPassword)
    res.success(null, '密码重置成功')
  }
}

module.exports = new UserController()
```

### 路由配置

```javascript
// user.route.js
const express = require('express')
const router = express.Router()
const userController = require('./user.controller')

// 通用 CRUD 路由（BaseController 已提供）
router.get('/list', userController.getList)
router.get('/all', userController.getAll)
router.get('/:id', userController.getById)
router.post('/', userController.create)
router.put('/:id', userController.update)
router.delete('/:id', userController.delete)

// 自定义路由
router.post('/reset-password', userController.resetPassword)

module.exports = router
```

### BaseService 提供的方法

| 方法 | 说明 |
|------|------|
| getList(params, lang) | 分页查询列表 |
| getAll(lang) | 获取所有数据（下拉选择用） |
| getById(id, lang) | 根据 ID 获取详情 |
| create(data) | 创建数据 |
| update(id, data) | 更新数据 |
| delete(id) | 删除数据 |
| batchDelete(ids) | 批量删除 |

| processLangFields(data, lang) | 处理多语言字段 |

### BaseController 提供的方法

| 方法 | 说明 | 路由 |
|------|------|------|
| getList(req, res) | 分页查询列表 | GET /list |
| getAll(req, res) | 获取所有数据 | GET /all |
| getById(req, res) | 根据 ID 获取详情 | GET /:id |
| create(req, res) | 创建数据 | POST / |

| delete(req, res) | 删除数据 | DELETE /:id |

## 最佳实践 <a name="best-practices"></a>

### 1. 新建标准 CRUD 页面

1. **后端**：
   - 创建 Model，继承 BaseModel
   - 创建 Service，继承 BaseService，重写 buildWhere
   - 创建 Controller，继承 BaseController
   - 创建 Route，配置通用 CRUD 路由 + 自定义路由

2. **前端**：
   - 创建 API 接口文件
   - 使用 `useCrud` 组合式函数
   - 使用 `FormDialog` 组件处理新增/编辑
   - 使用 `feedback.js` 处理消息提示和确认弹窗

### 2. 复杂页面的处理

对于有特殊业务逻辑的页面（如角色权限分配、设备管理），建议：
- 列表部分可以使用 `useTable` 或自己实现
- 弹窗部分可以使用 `FormDialog` 或自己实现
- 确认弹窗使用 `ConfirmDialog` 或 `feedback.js` 的 `confirmDelete`
- 消息提示统一使用 `feedback.js`

### 3. 代码规范

- 所有消息提示统一使用 `feedback.js`，不要直接使用 Element UI 的 Message
- 所有确认弹窗优先使用 `feedback.js` 的确认方法，复杂场景使用 `ConfirmDialog` 组件
- 新增/编辑弹窗优先使用 `FormDialog` 组件
- 标准 CRUD 页面优先使用 `useCrud` 组合式函数
- 后端新模块优先继承 `BaseService` 和 `BaseController`

### 4. 迁移现有代码

现有代码不强制迁移，建议：
- 新功能使用新的通用组件和工具
- 旧功能在迭代时逐步迁移
- 迁移时先在测试环境验证，确保功能不受影响
