## 📖 项目简介

nexCM-V3 是一套面向医疗设备行业的企业级后台管理系统，专为移动式灌装加塞设备设计。系统采用前后端分离架构，前端基于 Vue 2 + Element UI 技术栈，提供设备管理、生产管理、系统管理、通知中心、审计追踪等核心功能模块。

系统具有以下特点：
- **国际化支持**：完整的中英文双语支持，可扩展多语言
- **权限管理**：细粒度的权限控制，支持菜单、按钮、参数三级权限
- **审计追踪**：完整的操作审计日志，满足 FDA 21 CFR Part 11 合规要求
- **通知中心**：可配置的通知事件，支持邮件通知
- **设备监控**：实时 PLC 数据采集，设备状态监控
- **部件寿命管理**：部件寿命追踪，模板化管理，定时预警
- **电子签名**：关键操作二次身份验证，确保操作不可否认

### 架构设计

#### 1. 分层架构

系统采用经典的前后端分离分层架构：

```
┌─────────────────────────────────────────────────────┐
│                     视图层 (Views)                    │
│  页面组件、业务组件、布局组件、弹窗、表单等          │
├─────────────────────────────────────────────────────┤
│                     状态层 (Store)                    │
│  Vuex 全局状态管理：用户、权限、配置、字典等        │
├─────────────────────────────────────────────────────┤
│                     服务层 (API)                      │
│  API 接口封装、HTTP 请求拦截、响应处理              │
├─────────────────────────────────────────────────────┤
│                     工具层 (Utils)                    │
│  通用工具函数、认证、权限、日期、验证、导出等       │
├─────────────────────────────────────────────────────┤
│                     基础层 (Core)                     │
│  Vue 框架、路由、国际化、组件库、指令、过滤器       │
└─────────────────────────────────────────────────────┘
```

#### 2. 路由设计

- **静态路由**：登录、错误页、重定向等不需要权限的页面
- **动态路由**：根据用户权限动态生成的业务页面路由
- **路由守卫**：全局前置守卫，验证登录状态和页面权限
- **路由缓存**：支持页面缓存（keep-alive），提升用户体验

#### 3. 状态管理

采用 Vuex 模块化状态管理：
- **user 模块**：用户信息、登录状态、Token 管理
- **permission 模块**：权限列表、动态路由、按钮权限
- **app 模块**：应用配置、侧边栏状态、设备类型
- **settings 模块**：系统设置、主题、布局配置
- **dict 模块**：字典数据缓存
- **notification 模块**：通知状态、未读数量

#### 4. 权限设计

三级权限控制体系：
1. **菜单权限**：控制侧边栏菜单的显示和隐藏
2. **按钮权限**：控制页面按钮的显示和隐藏（v-permission 指令）
3. **参数权限**：控制配置参数的查看和修改（细粒度控制）

## 🚀 快速开始

### 环境要求

- Node.js >= 14.0.0
- npm >= 6.0.0
- 后端服务已启动（默认端口 3000）

### 安装步骤

#### 1. 克隆项目

```bash
git clone <仓库地址>
cd 02.01.02-nexCM-V3
```

#### 2. 安装依赖

```bash
npm install
```

#### 3. 配置环境变量

复制 `.env.example` 为 `.env.development` 和 `.env.production`，并根据实际情况修改配置：

```bash
# 开发环境配置
cp .env.example .env.development

# 生产环境配置
cp .env.example .env.production
```

环境变量说明：
```env
# 页面标题
VUE_APP_TITLE = nexCM管理系统

# 后端接口地址
VUE_APP_BASE_API = http://localhost:3000

# 端口号
VUE_APP_PORT = 8082

# 是否开启 mock
VUE_APP_MOCK = false
```

#### 4. 启动开发服务器

```bash
npm run serve
```

启动成功后，访问 `http://localhost:8082`

#### 5. 构建生产版本

```bash
npm run build
```

构建产物在 `dist/` 目录下。

#### 6. 代码检查

```bash
npm run lint
```

## 📱 项目功能

### 1. 首页模块

#### 功能介绍
首页模块提供系统概览、数据看板和数据管理功能，是用户登录后看到的第一个页面，展示系统核心指标和实时数据。

#### 功能模块

| 子模块 | 功能说明 |
|--------|----------|
| **概况预览** | 系统整体概况，设备数量、报警数量、生产订单、用户数量等核心指标 |
| **数据看板** | 数据可视化看板，设备状态趋势、报警统计、生产数据图表 |
| **数据管理** | 生产数据和报警数据的查看、导出、详情 |

#### 功能封装
- `views/home/overview/` - 概况预览页面
- `views/home/dashboard/` - 数据看板页面
- `views/home/data/` - 数据管理页面
- `store/modules/` - 首页相关状态管理
- `api/` - 首页相关 API 接口

#### 功能使用
1. 登录系统后自动跳转到首页
2. 通过顶部 Tab 切换概况预览、数据看板、数据管理
3. 在数据管理页面可按时间范围筛选数据，支持导出 Excel/PDF

#### 后续功能拓展
- 自定义看板布局，用户可自由拖拽组件
- 更多图表类型支持（雷达图、热力图、关系图等）
- 数据对比功能（同比、环比）
- 实时数据刷新（WebSocket 推送）

### 2. 设备管理模块

#### 功能介绍
设备管理模块提供设备状态监控、报警统计和部件寿命管理功能，是系统的核心业务模块，实现对移动式灌装加塞设备的全面监控和管理。

#### 功能模块

| 子模块 | 功能说明 |
|--------|----------|
| **设备状态** | 实时设备状态监控，PLC 数据采集，设备在线/离线状态 |
| **报警统计** | 报警信息统计和管理，报警详情查看，报警处理，报警导出 |
| **部件寿命** | 部件寿命追踪管理，模板管理，寿命预警，更换记录 |

#### 功能封装

**设备状态**：
- `views/device/state/` - 设备状态页面
- `store/modules/device.js` - 设备状态管理
- `api/device.js` - 设备相关 API
- `utils/plc.js` - PLC 数据处理工具

**报警统计**：
- `views/device/alarm/` - 报警统计页面
- `api/alarm.js` - 报警相关 API
- 支持统计看板和详细记录两个 Tab

**部件寿命**：
- `views/device/part/` - 部件寿命页面
- `views/device/part/components/PartTemplateManager.vue` - 模板管理组件
- `api/devicePart.js` - 部件寿命相关 API
- 支持寿命详情和模板管理两个 Tab

#### 功能使用

**设备状态**：
1. 进入设备管理 → 设备状态
2. 查看设备实时状态（在线/离线、运行参数）
3. 查看 PLC 实时数据采集

**报警统计**：
1. 进入设备管理 → 报警统计
2. 切换统计看板/详细记录 Tab
3. 查看报警列表，按级别、类别、时间筛选
4. 处理报警，导出报警记录

**部件寿命**：
1. 进入设备管理 → 部件寿命
2. 切换寿命详情/模板管理 Tab
3. 寿命详情：查看部件寿命状态，新增/编辑/删除部件，部件更换录入
4. 模板管理：管理部件模板（基础模板不可编辑/删除），新增模板基于基础模板

#### 后续功能拓展
- 设备远程控制（启动、停止、参数调整）
- 设备维护计划和保养提醒
- 设备 OEE（整体设备效率）分析
- 部件寿命预测算法（基于历史数据）
- 部件库存管理和采购提醒
- 设备故障诊断和智能推荐

## 📝 开发规范

### 代码规范

项目使用 ESLint 进行代码质量检查，遵循以下规范：
- 使用 2 空格缩进
- 使用单引号
- 语句末尾不加分号
- 变量命名使用 camelCase
- 组件命名使用 PascalCase
- 禁止使用 console.log（生产环境）
- 禁止使用 debugger（生产环境）

### Git 提交规范

项目使用 Husky + lint-staged 进行 Git 提交前检查：
- 提交前自动运行 ESLint 检查
- 自动修复可修复的代码问题
- 代码检查通过后才能提交

- 组件文件使用 `.vue` 单文件组件格式
- 使用 Vue 2.7 Composition API（`<script setup>`）

## 🐛 常见问题

### 1. 依赖安装失败

**问题**：`npm install` 失败或速度慢

**解决方案**：
```bash
# 使用国内镜像源
npm config set registry https://registry.npmmirror.com

# 或使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

### 2. 端口被占用

**问题**：启动时提示端口 8082 被占用

**解决方案**：
```bash
# 查看端口占用
netstat -ano | findstr 8082

# 结束占用进程
taskkill /F /PID <进程ID>

# 或修改端口号（.env.development）
VUE_APP_PORT = 8083
```

### 3. 接口请求失败

**问题**：页面提示接口请求失败

**解决方案**：
1. 确认后端服务已启动（默认端口 3000）
2. 检查 `.env.development` 中的 `VUE_APP_BASE_API` 配置
3. 检查浏览器控制台的网络请求，确认请求地址是否正确
4. 检查后端日志，确认接口是否正常

### 4. 页面空白

**问题**：登录后页面空白，控制台报错

**解决方案**：
1. 清除浏览器缓存和 Cookie
2. 重新登录系统
3. 检查用户权限是否正确配置
4. 检查路由配置是否正确

### 5. 国际化不生效

**问题**：切换语言后部分文本不变化

**解决方案**：
1. 检查对应语言包中是否有该 key
2. 检查 key 拼写是否正确
3. 清除浏览器缓存后重新加载
4. 检查是否使用了硬编码文本
