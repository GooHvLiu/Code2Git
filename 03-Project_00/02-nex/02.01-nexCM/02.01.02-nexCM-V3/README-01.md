| 中文菜单    | 推荐英文     | 说明                                   |
| :---------- | :----------- | :------------------------------------- |
| 网站首页    | Home         | 首页入口，简短直观                     |
| ---概况预览 | ---Overview  | 重大事项的预览                         |
| ---数据看板 | ---Dashboard | 适合图表、实时数据总览                 |
| ---数据管理 | ---DataView  | 偏向详细数据查看，比 DataManage 更简洁 |
| 设备管理    | Device       | 设备相关模块统一归口                   |
| ---设备状态 | ---DevState  | 适合心跳、运行、空闲、故障、离线状态   |
| ---报警统计 | ---AlarmLog  | 工控场景常用，简洁且专业               |
| ---部件寿命 | ---PartLife  | 比 PartLife 更贴近“寿命周期”含义       |
| 生产管理    | Production   | 生产相关模块统一归口                   |
| ---配方管理 | ---RecipeDB  | PLC 配方展示场景非常常用               |
| ---订单管理 | ---OrderLog  | 适合订单统计、历史记录管理             |
| 系统设置    | Settings     | 系统配置类入口                         |
| ---数据字典 | ---DictData  | 比 DataDict 更短，视觉更整齐           |
| ---角色管理 | ---UserRole  | 工程师、管理员、操作员等角色管理       |
| ---部门管理 | ---DeptInfo  | Departments 过长，Depts 更整齐         |
| ---用户管理 | ---UserData  | 用户账号、权限、同步管理               |
| ---审计追踪 | ---AuditLog  | 登录、创建、修改、打印追踪             |





| 页面元素         | 数据来源（PLC 地址）                                | 说明                                   |
| ---------------- | --------------------------------------------------- | -------------------------------------- |
| 设备状态         | M5001（运行）/ M5002（空闲）/ M5003（故障）         | 三个布尔值，哪个为 true 就是哪个状态   |
| 当前运行速度     | D4010                                               | 单位：瓶 / 小时                        |
| 今日产量         | D4004                                               | 当天累计灌装数量                       |
| 本班产量         | D4002                                               | 当前班次累计灌装数量                   |
| 累计总产量       | D4000                                               | 总得卡式瓶灌装数量                     |
| 实时报警代码     | D4012                                               | 当前报警代码（0 表示无报警）           |
| 报警详情         | M4000-M4110                                         | 50+ 种报警标志位，需要映射表           |
| 每批开始时间     | D4014                                               | 当前批次开始时间                       |
| 每批结束时间     | D4016                                               | 当前批次结束时间（未结束为 0）         |
| 今日正常运行时间 | D4020                                               | 单位：小时                             |
| 今日总停机时间   | D4022                                               | 单位：小时                             |
| 填充量目标设置   | D4512                                               | 单位：ml                               |
| 产量趋势图       | 需要后端定时采集 D4004 并存储历史数据               | PLC 只提供当前值，历史趋势需要后端记录 |
| OEE 综合效率     | 需要后端计算：运行时间 / 计划时间 × 性能率 × 合格率 | PLC 不直接提供，需要后端计算           |
