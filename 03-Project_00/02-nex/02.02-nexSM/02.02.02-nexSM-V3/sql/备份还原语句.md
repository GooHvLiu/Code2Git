##### 备份数据库

1.只备份数据库结构（不包含数据）

```bash
# 备份结构（使用 --result-file 直接写入文件）
mysqldump -u root -p --default-character-set=utf8mb4 --set-charset -d --routines --triggers --events --set-gtid-purged=OFF --result-file="nexsm_v2_dev_structure_v3_04-001.sql" nexsm_v2_dev
```

2.只备份数据库数据（不包含结构）

```bash
# 备份数据（使用 --result-file 直接写入文件）
mysqldump -u root -p --default-character-set=utf8mb4 -t --complete-insert --result-file="nexsm_v2_dev_data_v3_04-001.sql" nexsm_v2_dev

```

##### 恢复数据库

方法一：先恢复结构，再恢复数据

```bash
# 1. 先恢复数据库结构
mysql -u root -p nexsm_v2_dev < nexsm_v2_dev_structure_20260827.sql

# 2. 再恢复数据库数据
mysql -u root -p nexsm_v2_dev < nexsm_v2_dev_data_20260827.sql
```

方法二：恢复到新的数据库

```bash
# 1. 创建新的数据库
mysql -u root -p -e "CREATE DATABASE nexsm_v2_dev_new CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 先恢复数据库结构
mysql -u root -p nexsm_v2_dev_new < nexsm_v2_dev_structure_20260827.sql

# 3. 再恢复数据库数据
mysql -u root -p nexsm_v2_dev_new < nexsm_v2_dev_data_20260827.sql
```
