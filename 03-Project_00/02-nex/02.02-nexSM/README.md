##### _nexSM-V2_03_

- _增加plc模块管理和使用，支持 ModbusTcp(默认) / S7 / OpcUa;_
- _增加 基础 审计追踪功能：操作记录和查询记录；_
- _对应前端的02.01.02-nexCM-V2_04.zip版本；_
- _距离专业审计追踪还需要：_
- _第一阶段_

1. 审计日志表加触发器，禁止 UPDATE/DELETE
2. 关键操作（写 PLC、删用户）增加电子签名弹窗（密码 + 原因）
3. 扩大审计覆盖范围（登录 / 登出 / 用户管理 / 导出）
4. 增加密码安全策略

- _第二阶段_

5. 审计日志哈希链校验
6. NTP 时间同步配置
7. 操作超时自动登出

- _第三阶段_

8. 编写 CSV 验证文档（URS/FS/DS/IQ/OQ/PQ）
9. 制定 SOP（标准操作规程）
10. 用户培训记录
